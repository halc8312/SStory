# microtexture-v2-r3 preregistration

The adjacent JSON is normative. r3 is technically blinded: all render seeds and opaque codes are HMAC-derived with a cryptographically random 32-byte secret supplied as exactly 64 hexadecimal characters through `MICROTEXTURE_V2_R3_BLIND_KEY`. Only its one-way commitment may enter an artifact or report. Git subprocesses never inherit the secret.

Vision labels use `clean`, `warning`, or `reject`. Hard thresholds learn only from controls carrying the matching visible label and `reject`; warning thresholds learn from all matching visible controls. Only hard thresholds participate in acceptance and rejection. Warning hits are reported separately, while warning-disposition controls must retain at least 0.75 hard-composite acceptance in both splits. If no warning-disposition controls exist, the measure is explicitly not applicable, is reported as vacuous 1.0, and carries `warning_acceptance_applicable: false`; no warning labels are forced to satisfy a quota.

Holdout is impossible until calibration freeze and the one-shot locked-positive validation have been completed and an eligible independent reviewer (`Cicero the 2nd` or `Descartes the 2nd`, matched after NFKC/casefold/whitespace normalization) has approved a receipt binding their exact hashes at the preregistered tracked path. Timestamp order is validated in UTC. This is procedural trusted-agent assurance from a preregistered allow-list and tracked receipt; it is not a cryptographic signature or proof of human identity. The locked positive must pass every hard threshold. Every action requires captured HEAD to equal the current branch upstream, reads authority blobs from that captured pushed commit, and confirms HEAD is unchanged at completion.

Execution is permitted only when `CODE_ROOT` is exactly `scripts/map-production/microtexture-v2-r3`, committed, and equal to the current branch upstream. Any review copy elsewhere—including a temp copy—fails before mutation.
