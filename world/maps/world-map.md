# 世界地図 - エターナル・アルカディア

## 世界地図の基本情報

### 投影法
**エターニア投影法**: 球形に近い五大陆を平面に表現した独自投影法

### 縮尺
**1cm = 約500km**（実寸約50,000kmの外周）

## 五大陸地図

### エルディア（中央大陸）
**位置**: 世界の中心
**形状**: ほぼ円形、中央に山脉
**面積**: 約120万km²

#### 主要地形
```
       北
       ↑
    ┌─────┐
    │ 天翔 │← 山脈（中央山脉）
    │山脈  │
    ├─────┤
    │ 王都│→ 平原
    │ 地方 │
    ├─────┤
    │ 銀の│→ 平野
    │ 平野 │
    └─────┘
       南
```

**主要地点**:
- **アストラリス**: 北東部、首都
- **天翔山脈**: 中央、南北に貫く
- **銀の平野**: 南部、穀倉地帯
- **月影の森**: 北西部、エルフの領地

---

### リュミエラ（東大陸）
**位置**: エルディアの東
**形状**: 長方形、東海岸に浮島群
**面積**: 約80万km²

#### 主要地形
```
北
↑
┌───────────┐
│ エメラルド│
│ ・ベルト │← 森（70%を占める）
├───────────┤
│ 月影遺跡 │
│   群     │
├───────────┤
│朝霧海岸 │
│          │← 浮島群（リュミエラ・アーチ）
└───────────┘
南
```

**主要地点**:
- **エメラルド・ベルト**: 全域に広がる大森林
- **月影遺跡群**: 中央部、古代ルナリア帝国の遺跡
- **朝霧海岸**: 東海岸、浮島群が浮かぶ
- **浮島群**: 海上に浮かぶ数百の島

---

### カオス・リア（南大陸）
**位置**: エルディアの南
**形状**: 逆三角形、砂漠が中心
**面積**: 約100万km²

#### 主要地形
```
北（エルディアに接続）
↑
┌─────────────┐
│翡翠のオアシス│
│              │← オアシス都市群
├─────────────┤
│ 紅海砂漠    │
│            │← 砂漠（60%）
├─────────────┤
│炎の大地    │
│（火山地帯） │
└─────────────┘
南
```

**主要地点**:
- **紅海砂漠**: 中央部、世界最大の砂漠
- **翡翠のオアシス**: 北部、複数のオアシスが集まる
- **炎の大地**: 南部、活火山地帯
- **砂嵐の渓谷**: 東部、天然の要害

---

### アトランティス（西大陸）
**位置**: エルディアの西
**形状**: 南北に細長い、フィヨルドが特徴
**面積**: 約60万km²

#### 主要地形
```
北
↑
┌───────┐
│永久凍土│
├───────┤
│ 鉄山 │← 山脈
│ 脈   │
├───────┤
│ フィ │
│ ヨル │← 海岸
│ ド   │
├───────┤
│ 氷河│
│ 都市│
└───────┘
南
```

**主要地点**:
- **永久凍土**: 北部、一年中雪に覆われる
- **鉄山脉**: 中央部、魔導金属の産地
- **フィヨルド群**: 西部、複雑な海岸線
- **氷河都市**: 南部、ドワーフの要塞都市

---

### グリモワール（北大陸）
**位置**: エルディアの北
**形状**: 小さな丸い大陸
**面積**: 約40万km²

#### 主要地形
```
北
↑
┌─────────┐
│ 大結節点 │
│（エターニア│
│  ・コア） │← 精霊力の源

│          │← 時間の歪み
├─────────┤
│封印の地  │
│          │← 古代兵器
└─────────┘
南（エルディアに接続）
```

**主要地点**:
- **大結節点「エターニア・コア」**: 北部、精霊力の源泉
- **時の迷宮**: 中央部、時間の歪みの迷宮
- **封印の地**: 南部、古代兵器と禁断の魔法
- **精霊の門**: 南西部、精霊界との境界

## 海域と海

### 1. 中央海（Central Sea）
**位置**: 五大陸を囲む内海
**面積**: 約200万km²
**特徴**:
- 比較的穏やか
- 交易の中心
- 島が点在

**主要島**:
- **ポートゼフィア島**: ゼフィア連合の贸易港
- **翡翠島**: 翡翠王国の領土
- **月影島**: エルフの聖地

---

### 2. 外海「ヴォイド・オーシャン」（Void Ocean）
**位置**: 中央海の外側
**面積**: 無限（未探査）
**特徴**:
- 未探査海域が大部分
- 海 monsters 多発
- 嵐が頻発

**警戒区域**: 沿岸から500km以遠は航行禁止

---

### 3. 星の海（Sea of Stars）
**位置**: 浮島群の下
**特徴**:
- 夜になると星のように光る
- 特殊な海洋生物
- 浮島の影で日の光が届かない

---

## 浮島群

### 1. リュミエラ・アーチ（Lumiera Arch）
**位置**: リュミエラ東海岸沖
**島数**: 約200島
**高さ**: 海抜500m～2,000m
**特徴**: 月の精霊の力が強い

**主要島**:
- **月影島**: 最大の島、エルフの研究施設
- **風の島**: 風魔法の修行場
- **星屑島**: 天文台がある

---

### 2. スカイ・チェーン（Sky Chain）
**位置**: エルディア中央上空
**島数**: 約300島
**高さ**: 海抜3,000m～10,000m
**特徴**: 嵐の都の本拠地

**主要島**:
- **ストーム・キーパー**: 嵐の都の首都島
- **ポート・スカイ**: 空中港
- **風の島**: 風魔法研修所

---

### 3. 星屑群島（Stardust Islands）
**位置**: カオス・リア南西沖
**島数**: 約100島
**高さ**: 海抜1,000m～4,000m
**特徴**: 夜に美しい光を放つ

---

### 4. 嵐の浮島（Storm Isles）
**位置**: アトランティス北西沖
**島数**: 約50島
**高さ**: 海抜2,000m～6,000m
**特徴**: 常に嵐に覆われている

---

## 地図の凡例

### 地形記号
- **▲**: 山（標高3,000m以上）
- **△**: 丘（標高500～3,000m）
- **━**: 平野（標高500m以下）
- **≈**: 湿地・沼地
- **▓**: 森
- **▒**: 砂漠
- **░**: 雪原・氷河

---

### 種族分布
- **赤**: 人間（ゼフィア連合・翡翠王国）
- **青**: エルフ（月影エルフ王国）
- **灰**: ドワーフ（鉄山脉王国）
- **緑**: オーク（赤砂オーク連合）
- **茶**: ハーフリング（郷士連合）
- **紫**: Triton（アトランティス）
- **橙**: その他（浮島群など）

---

### 精霊力の強さ
- **深紅**: 極めて強い（大結節点周辺）
- **赤**: 強い（精霊聖域）
- **黄**: 中程度（通常地域）
- **青**: 弱い（枯渇地域）
