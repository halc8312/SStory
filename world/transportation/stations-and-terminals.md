# 交通拠点一覧 - エターナル・アルカディア

## 概要

エターナル・アルカディアの交通網を支える**交通拠点**には、駅馬車宿、関所、港湾、空港、浮島埠頭など多様な施設がある。これらは交通の結節点として、乗客・貨物・乗り物の**中継・管理・安全確保**の役割を担っている。

## 拠点種別の体系

| 種別 | 主な機能 | 陸上 | 海上 | 空中 |
|------|----------|------|------|------|
| 駅馬車宿 | 乗客・乗り物の中継・休憩 | ● | - | - |
| 関所 | 通行税徴収・検問・安全確認 | ● | - | - |
| 港 | 船舶係留・荷役・税関 | - | ● | - |
| 空港 | 航空機離着陸・旅客サービス | - | - | ● |
| 浮島埠頭 | 浮島着岸・浮島船中継 | - | - | ● |
| 隊商宿 | 隊商の中継・物資補給 | ● | - | - |
| 巡礼宿 | 巡礼者の宿泊・儀式 | ● | - | - |
| 税関 | 出入国審査・関税徴収 | ● | ● | ● |
| 検疫所 | 病気・危険物チェック | ● | ● | ● |
| 魔導灯台 | 航路誘導・安全監視 | ● | ● | ● |

## 拠点の分類体系

### 規模による分類

| 規模 | 定義 | 例 |
|------|------|----|
| 国際ハブ | 全大陸からの利用者・国際線発着 | アストラリス中央駅馬車広場・ポートゼフィア港 |
| 国家ハブ | 一国の中心・主要路線発着 | グランロック北門宿・翡翠港 |
| 地域中継 | 地域内交通の中継点 | ブラッド・フォート隊商門 |
| 地方拠点 | 地方の小さな拠点 | 月影の森巡礼宿 |
| 特殊拠点 | 特殊目的（監視・警備） | 北関所・風の休息所 |

---

### 機能による分類

**運輸機能**:
- 乗客中継: 駅馬車宿・空港
- 貨物中継: 港湾・倉庫
- 乗り物中継: 浮島埠頭・給油所

**管理機能**:
- 税関: 出入国審査・関税
- 検疫: 病気・危険物検査

**安全機能**:
- 灯台: 航路誘導
- 監視所: 安全監視
- 避難所: 災害時避難

**サービス機能**:

## 安全設備基準

### 全拠点に必須の設備

1. **通信石**: 緊急連絡用（24時間監視）
2. **魔導灯**: 常時照明（停電時も可）
3. **救命設備**: 救命ボート・浮遊ポーチ
4. **医療所**: 魔導士常駐（大規模拠点）または 常駐医師（小規模）
5. **防御結界**: D級以上（危険地域のみ）

   - スカイ・チェーンに5ヶ所新設
   - 浮島間輸送の効率化

2. **共同税関**:
   - 主要3港に**共同税関**設置（手続き一元化）
   - 所要時間50%短縮

3. **緊急救助基地**:
   - 各主要街道沿いに5ヶ所新設
   - 24時間救急体制

---

### 長期（100年以内）

1. **空中ハブ空港**:
   - 嵐の都に**メガ空港**建設（発着能力200機/時）
   - 全大陸の空中交通集中

2. **海底ターミナル**:
   - アトランティスと翡翠王国を結ぶ**海底ターミナル**（2ヶ所）
   - 潜水艇の中継基地

3. **時空ゲート駅**:
   - グリモワールに**瞬間移動ゲート駅**（理論段階）
   - 時間短縮交通の実現
