# 交通網・公共交通設定 総合ガイド

## はじめに

本書類は、エターナル・アルカディア世界における**交通網・公共交通機関の総合設定**である。ここでは、単なる移動手段としての道や航路ではなく、それらが**国家・交易・戦争・信仰・魔法文明の歴史とどのように結びついて発展してきたか**を制度として定義する。

## 交通網の位置づけ

エターナル・アルカディアにおける交通網は、以下の**5つの柱**によって支えられている：

1. **歴史的経緯** - 三大古代文明からの継承と断絶
2. **地理的条件** - 大陸形状・気候・地形による制約と影響
3. **国家間協力** - 十二国同盟による標準化と共同管理
4. **魔法技術** - 精霊契約と魔導技術の融合
5. **経済活動** - 交易路としての実用的価値

## 交通制度の特徴

### 1. 精霊契約に基づく運用

すべての公共交通手段は、何らかの形で**精霊との契約**に基づいて運用されている：
- 風の精霊ゼフ - 推進力・浮遊
- 地の精霊グラン - 路盤強化・地下鉄
- 水の精霊ハイドロ - 海上航行・潮流制御
- 火の精霊ピュロス - 動力源・蒸気機関
- 月の精霊ルナ - 空中浮遊・時空操作（古代技術）

### 2. 国家間標準化

**十二国同盟**のもと、以下の項目で全大陸共通基準が適用されている：
- 道路規格（幅員・舗装材・標識）
- 船舶・航空機の安全基準
- 運転・操縦免許の相互認証
- 緊急通信・救助体制
- 関税・検疫・税関手続き

### 3. 公共交通の公共性

- **国家交通庁**（ゼフィア） - 陸上交通の基準策定・監査
- **海上交通連合** - 海上安全・港湾管理
- **空中交通公社**（嵐の都） - 浮島航路・空域管理
- **精霊協会** - 環境配慮・精霊共存交通の推進

## 交通網の歴史的変遷

交通網は以下の**5つの時代**を経て現在に至る：

1. **第一期：古代道の時代**（-10,000年～-5,000年）
   - 精霊門・聖地・遺跡を結ぶ巡礼路の成立
   - 地脈と精霊の力による初期道路

2. **第二期：王国街道の時代**（-5,000年～-1,000年）
   - 王都アストラリスを中心とする行政・軍事街道網
   - 古代エリュシオン王国による整備

3. **第三期：交易路の時代**（-1,000年～0年）
   - 港湾都市・鉱山都市・オアシスを結ぶ交易路拡張
   - 商人ギルド主導の国際航路成立

4. **第四期：十二国同盟の再整備**（0年～アールディー500年）
   - 戦争・災害で荒廃した道の標準化
   - 駅馬車制度・関所・定期便の確立

5. **第五期：魔導交通の時代**（アールディー500年～現在）
   - 風魔法船・魔導列車・浮島航路の発達
   - 海と空の交通網の完成

詳細は [history.md](history.md) を参照。

## 交通路の成立理由分類

各交通路は以下の**7つの目的**によって成立した：

| 分類 | 内容 | 例 |
|------|------|----|
| 王権・行政 | 王都と地方を結ぶ統治路 | 中央街道 |
| 軍事 | 要塞・国境・峠へ向かう軍道 | 北方街道（仮称） |
| 交易 | 港・鉱山・穀倉地帯を結ぶ道 | 紅海砂漠隊商路 |
| 巡礼 | 神殿・精霊の泉・聖地へ向かう道 | 月影の森巡礼路 |
| 開拓 | 辺境村・農地・鉱山街の成立に伴う道 | 鉄山脉矿石道 |
| 災害避難 | 火山・砂嵐・魔力汚染地帯を避ける迂回路 | 北部迂回路 |
| 魔法的理由 | 地脈・精霊門・浮島に沿う道 | 精霊街道 |

## 公共交通制度の基本原則

### 運行の安全基準
- 全交通手段は**国家交通庁**の安全検査を年1回受検必須
- 魔導士が乗務する交通手段は、B級以上の免許所持者限定
- 危険海域・危険空域は季節・天候により運休

### 運賃・料金体系
- 国家間路線は**十二国同盟**により運賃上限が規定
- 地方路線は各国家の交通局が適正価格を決定
- 巡礼者・学生・高齢者には割引制度あり

### 緊急対応
- **魔導士救急隊**が主要都市に配置（陸上・海上・空中共通）
- 通信石により全交通機関が24時間緊急連絡可能
- 自然災害時は**交通優先権**が発動（緊急車両最優先）

## 今後の交通網整備計画

### 短期（10年以内）
1. 魔導列車のゼフィア→ドワーフ間延伸
2. 浮島間ケーブルカー（嵐の都→リュミエラ）開通
3. 主要道路の100%舗装完了

### 中期（30年以内）
1. 海底トンネル（アトランティス→翡翠王国）完成
2. 大陸横断地下トンネル（エリュシオン→グリモワール）開通
3. 全大陸交通ネットワークのAI最適化

### 長期（100年以内）
1. 時空間ゲートの安全実現（古代技術の復元）
2. 環境負荷ゼロ交通（100%再生可能エネルギー）
3. 全大陸交通格差の解消
