# 交通網・公共交通設定 概要 - エターナル・アルカディア

## はじめに

本ファイルは、エターナル・アルカディア世界における**交通網・公共交通制度**の全体概要をまとめる。交通は単なる移動手段ではなく、**国家・交易・戦争・信仰・魔法文明の歴史と深く結びついた社会基盤**として位置づけられる。

## 交通の三体系

エターナル・アルカディアの交通網は、以下の三体系によって構成される：

### 1. 陸路（Road Network）

**主要街道**が五大陸を結び、国家間の物流・人流を支える。

- **中央街道**：王都アストラリスとグランロックを結ぶ最重要道
- **東方街道**：エリュシオンとリュミエラを結ぶ森林外交路
- **南方街道**：銀の平野・カオス・リア・紅海砂漠を結ぶ交易路
- **西方街道**：アトランティス・鉄山脉・マリンポートを結ぶ鉱石交易路
- **地方街道**：各国内の都市・村を結ぶ生活道路

### 2. 海路（Sea Routes）

**中央海**を中心とした海上航路網が、大陸間の海上輸送を担う。

- **中央海定期航路**：ゼフィア・アトランティス・翡翠王国を結ぶ大動脈
- **リュミエラ海岸航路**：月影エルフ王国とゼフィアを結ぶ観光・交易路
- **赤砂海岸航路**：赤砂オーク連合と翡翠王国を結ぶ砂漠交易路
- **北大洋航路**：ドワーフとグリモワールを結ぶ季節限定航路

### 3. 空路（Sky Routes）

**浮島航路**と**魔導飛行船**による空中交通網。

- **スカイ・チェーン航路**：嵐の都を中心とした浮島航路ネットワーク
- **リュミエラ・アーチ航路**：月影エルフ方面の空中回廊
- **嵐の都空運網**：浮島国家独自の交通体系

## 公共交通の種別

以下の公共交通機関が運行されている：

| 交通種別 | 種別 | 主な利用者 | 運行頻度 |
|----------|------|------------|----------|
| 駅馬車 | 陸上・定期 | 一般人・商人 | 毎日～毎週 |
| 乗合馬車 | 陸上・路線 | 一般人・農民 | 毎日 |
| 隊商便 | 陸上・護衛付 | 商人・旅行者 | 週数次 |
| 定期船 | 海上・定期 | 旅客・商人 | 毎日～毎週 |
| 貨客混載船 | 海上・混合 | 一般人・商人 | 週数次 |
| 巡礼船 | 海上・宗教 | 巡礼者 | 季節限定 |
| 魔導飛行船 | 空中・定期 | 貴族・商人 | 毎日 |
| 浮島連絡船 | 空中・浮島間 | 一般・観光 | 毎日 |
| 緊急通信便 | 各交通 | 国家・軍 | 24時間 |

## 利用者層と交通網

### 一般市民
- 主に**駅馬車・乗合馬車**を利用
- 日常的な移動、市場へのアクセス、就労
- 運賃: 1-10金貨/日（平民向け）

### 商人・交易者
- **隊商便・定期船・貨客混載船**を利用
- 長距離交易、物品輸送
- 運賃: 20-100金貨/回（中級市民向け）

### 軍隊・軍事物資
- **専用輸送隊・軍用船・軍用飛行船**
- 緊急展開、物資輸送
- 国家管理・無料（公費）

### 巡礼者・信仰者
- **巡礼船・聖地巡回路**を利用
- 神殿・精霊の泉・聖地への訪問
- 季節限定・団体行動

### 貴族・上流階級
- **急行馬車・チャーター便・VIP飛行船**を利用
- 高速・快適・プライベートな移動
- 運賃: 100-1,000金貨/回（高級）

### 魔導士・魔法関係者
- **飛翔術・浮遊車両・魔導列車**を利用
- 魔導士免許が必要な交通手段
- B級以上の精霊契約が必要

## 交通の歴史的背景

交通網は、以下の**5つの歴史時代**を経て発展した：

1. **古代道の時代**：精霊門・聖地・遺跡を結ぶ巡礼路の起源
2. **王国街道の時代**：王都アストラリスを中心とした行政・軍事路の整備
3. **交易路の時代**：港湾都市・鉱山都市・砂漠オアシス間の交易路発展
4. **十二国同盟の再整備**：戦争・災害後の道路標準化・駅馬車化
5. **魔導交通の時代**：風魔法船・魔導飛行船・浮島航路の確立

## 交通の制度と管理

### 主要管理組織

- **国家交通庁**（ゼフィア）：陸上交通の基準制定・安全規制
- **海上交通連合**：海上安全・海難救助・港湾管理
- **空中交通公社**（嵐の都）：浮島航路・空中安全の一元管理
- **精霊協会 交通部**：環境配慮型交通の推進・精霊環境影響評価

### 交通法体系

- **道路利用法**：速度制限・通行権・免許制度
- **海上交通法**：航行規則・安全装備・海賊対策
- **空域法**：空域区分・飛行許可・安全規制

3. **制度レイヤー**：管理組織・法规・運営体制
4. **運用レイヤー**：運行頻度・運賃・利用者層・安全対策
5. **文化レイヤー**：地域ごとの交通文化・特徴・問題点
