# 戦闘ルール - エターナル・アルカディア

## 1. 戦闘の流れ

### 1.1 先制判定 (Initiative)

戦闘開始時、全参加者が **DEX 判定** を行う。

`1d20 + DEX修正 + その他ボーナス`

高い順にターンが進行。タイはGMが順序を決める。

### 1.2 ラウンドとターン

- **ラウンド**: 約6秒間。全員が1ターン行動する。
- **ターン**: 各キャラクターの行動順。以下の行動が可能：

```
あなたのターン:
1. 移動 (最大移動速度)
2. 標準行動 (攻撃、呪文、特殊能力)
3. ボーナスアクション (軽い行動、追加能力)
4. 反応 (他のキャラの行動に対して、1ラウンド1回)
```

## 2. 行動タイプ

### 2.1 移動 (Movement)

- **通常移動**: 速度 (通常30フィート = 9m) まで自由に移動。
- **ダッシュ**: 移動アクションを消費して速度2倍。
- **這う/忍び寄り**: 半速、隠密判定ボーナス/ペナルティ。

### 2.2 攻撃アクション (Attack Action)

- **単体攻撃**: 1回の攻撃ロール。
- **多体攻撃** (追加攻撃あり): レベルに応じ追加攻撃 (戦士など)。
- **范围攻撃**: 円錐、直線、球など (呪文や特殊能力)。

### 2.3 ボーナスアクション

特定のクラス能力、二刀流、一部呪文など。

### 2.4 反応 (Reaction)

- **機会攻撃**: 敵が移動範囲から出る時に攻撃。
- **呪文反射**: 一部呪文に対するセーブ。
- **特殊能力**: シールド、アンキャニー・ドッジなど。

## 3. 攻撃とダメージ

### 3.1 攻撃ロール (Attack Roll)

`1d20 + 攻撃ボーナス vs 目標のAC`

**攻撃ボーナス** = 能力修正（武器はSTRまたはDEX）+ 技能修得（Proficiency）+ 装備ボーナス + その他。

**命中時のダメージ**: 武器ダイス + 能力修正（STRまたはDEX、一部クラスはDEX）+ その他ボーナス。

### 3.2 クリティカルとファンブル

- **自然20**: 自動命中、ダメージダイスを2倍 (x2) + 修正を加える。
- **自然1**: 自動失敗、攻撃ミス。

### 3.3 ダメージタイプ

| タイプ | 例 | 耐性/弱点の例 |
|--------|----|---------------|
| 打撃 (Bludgeoning) | 槌、棍棒 | ゴーレム: 耐性 |
| 刺突 (Piercing) | 槍、矢 | スケルトン: 耐性 |
| 斬撃 (Slashing) | 剣、斧 | 植物: 弱点 |
| 火炎 (Fire) | ファイアーボール | ドラゴン: 弱点 |
| 冷気 (Cold) | アイスボルト | ホワイトタイガー: 弱点 |
| 電撃 (Lightning) | ライトニングボルト | 空中種: 耐性 |
| 酸 (Acid) | アシッドスプラッシュ | 金属: 弱点 |
| 毒 (Poison) | 毒の矢 | 不死: 無効 |
| 魔力 (Magic) | 魔力弾 | アンデッド: 弱点 |
| 月 (Moon) | 月の光弾 | 吸血鬼: 弱点 |
| 地 (Earth) | 岩石落とし | 昆虫: 耐性 |
| 風 (Wind) | 竜巻 | 飛行: 耐性 |
| 水 (Water) | 水流圧迫 | 火_elemental: 弱点 |

## 4. 防衛値 (Armor Class, AC)

`AC = 10 + DEX修正 + 装備AC + 盾 (+2) + 魔法ボーナス`

- **軽装**: AC = 11 + DEX
- **中装**: AC = 13 + DEX (最大2)
- **重装**: AC = 16 (DEX適用なし) + 盾

### 4.1 カバー (Cover)

- **半カバー**: +2 AC (+2 セーブ)
- **3/4カバー**: +5 AC (+5 セーブ)
- **完全カバー**: 攻撃不可能。

## 5. 状態異常 (Conditions)

| 状態 | 効果 |
|------|------|
| **危篤 (Dying)** | HP0、毎ラウンドCONセーブ (DC10) 成功で安定、失敗でHP-1 |
| **気絶 (Unconscious)** | 行動不能、自動失敗、攻撃クリティカル |
| **麻痺 (Paralyzed)** | 動けず、自動失敗、触れると追加効果 |
| **魅了 (Charmed)** | 敵対できず、防御不能 |
| **恐怖 (Frightened)** | 恐怖源から離れようとする、攻撃ロールペナルティ |
| **混乱 (Confused)** | ランダムに行動 (攻撃/移動/何もしない) |
| **石化 (Petrified)** | 行動不能、AC/セーブ低下、耐性なし |
| **盲目 (Blinded)** | 視界なし、AC低下、セーブペナルティ |
| **聴覚障害 (Deafened)** | 聴覚なし、判定ペナルティ |
| **抑制 (Restrained)** | 移動0、AC低下、DEXセーブペナルティ |
| **沈黙 (Silenced)** | 呪文成分 (V) 不可能 |
| **毒 (Poisoned)** | 攻撃ロール/セーブペナルティ |

## 6. 休憩と回復

### 6.1 短休憩 (Short Rest)

- 時間: 1時間以上。
- アクション: ヒールダイス (Hit Dice) を消費してHP回復。1ラウンドあたり1回まで。
- 他の回復能力も発動可能。

### 6.2 長休憩 (Long Rest)

- 時間: 8時間 (睡眠6時間以上)。
- 効果:
  - HP全回復
  - ヒールダイスリセット (半分を最低1つ)
  - 呪文スロット全回復
  - 状態異常の一部回復 (毒など)

## 7. 死亡と蘇生

- **死亡条件**: HPが **-10** 以下で死亡。
- **安定化**: HP0でCONセーブ (DC10) 成功 → 安定、1HPで復活 (短休憩後)。
- **蘇生魔法**: 復活術 (Revivify, 1分以内)、死者蘇生 (Raise Dead, 時間経過)、完全復活 (True Resurrection)。

## 8. 特殊状況

### 8.1 掩護 (Help Action)

味方が敵に攻撃する際、+2 ボーナスを付与 (位置による)。

### 8.2  grapple (組み付き)

STR/Athletics チェック vs 目標のSTR/DEX。成功で組み付き、移動可能。

### 8.3 押し倒し (Shove)

同様に押し倒し、 prone 状態にできる。

### 8.4 Disarm

攻撃ロール vs 目標のAC (武器を落とす)。ルールブック補足。

### 8.5 跳躍 (Jump)

STR/Athletics チェックで距離判定。

## 9. 環境による影響

- **高所**: 落下ダメージ、移動ペナルティ。
- **水中**: 移動半減、攻撃ペナルティ、窒息。
- **密林**: 隠密容易、移動困難。
- **砂漠**: 疲労増加、水消費。
- **極寒**: 凍傷ダメージ、移動低下。
- **高温**: 疲労、脱水。

## 10. 大規模戦闘

- **集団戦**: 軍隊レベルの戦闘は集団チェックで簡略化。
- **指揮**: リーダーのCHA/INTチェックで士気ボーナス。
- **戦術**: 陣形、包囲、撤退。
