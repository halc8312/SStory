# モンスター統計 (Bestiary Stats)

このドキュメントは、モンスターや敵対NPCのゲーム統計を定義するためのフォーマットと、サンプルデータを提供します。

## 1. 統計ブロック形式 (Stat Block)

すべてのクリーチャーは以下の形式で記述：

```markdown
### クリーチャー名 (CR X.Y)

**タイプ**: タイプ (例: 有人型, 怪物, 不死, 精霊, 構築物)
**アライメント**:  Lawful Good, Neutral, Chaotic Evil, etc.
**致命傷**: 〜点 (Optional)

**能力値**:
- STR: 値 (+修正)
- DEX: 値 (+修正)
- CON: 値 (+修正)
- INT: 値 (+修正)
- WIS: 値 (+修正)
- CHA: 値 (+修正)

**防御**:
- **AC**: 値 ( natural armor, shield, etc.)
- **HP**: 値 (Hit Dice) 例: 45 (6d8+12)
- **速度**: 移動速度 (フィート)、特殊移動 (fly, swim, climb)

**耐性・弱点**:
- ダメージ耐性: 火炎, 冷気, etc.
- ダメージ弱点: 電撃, 酸, etc.
- 状態耐性: 麻痺, 魅了, etc.

**感覚**: 暗視60フィート, 気配感知30フィート, etc.
**言語**: 理解する言語

**CR (Challenge Rating)**: X.Y
**経験値**: XX XP

---

### 能力 (Features)

**本能 (Keen Smell)**: 匂いの感知判定にadvantage。

**残忍攻撃 (Brutal Attack)**: クリティカル時に追加1d6ダメージ。

---

### 攻撃 (Actions)

** multid strikes (多撃)**: クリーチャーは本能的に2回攻撃。

**かみつき (Bite)**: *近接武器攻撃*: +5 命中,  reach 5 フィート., 1 target.
*Hit*: 1d6+3 刺突ダメージ + 毒 (DC12 CON save, 1d4 poison, 1分間)。

**火炎ブレス (Fire Breath)**: (再使用5ラウンド)
60フィート 円錐、DC13 DEX save, 失敗なら `3d6` 火炎ダメージ、成功なら半減。

---

### 反応 (Reactions)

**機会攻撃 (Opportunity Attack)**: 敵が移動範囲から出る時に通常攻撃。

---

### 伝説の行動 (Legendary Actions)

クリーチャーはラウンドに1～3回、他のキャラのターン後に伝説の行動を取れる。

- **監視 (Detect)**: 周囲30フィートの感知判定を行う。
- **翼の羽ばたき (Wing Beat)**: 周囲10フィートの全員を吹き飛ばす (STR save DC14、転倒)。
- **噛みつき (Bite)**: 1回の攻撃行動を追加。

```

## 2. CR (Challenge Rating) 計算式

CRは概算：

```
CR = (防御力 + 攻撃力 + 特殊能力) / 3 程度
```

簡易ガイド:

| 期待プレイヤーレベル | 推奨CR |
|----------------------|--------|
| 1-4 | 1/8 ～ 2 |
| 5-10 | 3 ～ 6 |
| 11-16 | 7 ～ 12 |
| 17-20 | 13 ～ 20 |

**目安**:
- CR1: レベル1パーティ4人に適度な挑戰。
- CR5: レベル5パーティに危険。
- CR10: レベル10パーティに致命的。

## 4. モンスター作成ガイドライン

### 4.1 バランス調整

- **HPとAC**: 同CRの平均HP/ACと比較。
- **攻撃力**: 1ラウンドあたりの期待ダメージ。
-**特殊能力**: CRに+0.5～2程度の価値を付与。

### 4.2 クリーチャータイプごとの特性

| タイプ | 特徴 | 例 |
|--------|------|----|
| アンデッド | 毒耐性、チャージなし, 致死傷耐性 | スケルトン |
| 構築物 | 免疫: 毒, 心理, 状態 (一部) | ゴーレム |
| 精霊 | 元素耐性, 特殊移動 | エレメンタル |
| ドラゴン | 高火力, ブレス, 高AC | ドラゴン |
| 人型 | 武器/防具使用, 言語 | オーク, ゴブリン |

## 5. 経験値と戦利品

### 5.1 経験値

モンスターのCRに基づく：

| CR | XP |
|----|----|
| 0 | 10 |
| 1/8 | 25 |
| 1/4 | 50 |
| 1/2 | 100 |
| 1 | 200 |
| 2 | 450 |
| 3 | 700 |
| 4 | 1,100 |
| 5 | 1,800 |
| 6 | 2,300 |
| 7 | 2,900 |
| 8 | 3,900 |
| 9 | 5,000 |
| 10 | 5,900 |

### 5.2 戦利品 (Treasure)

CRに応じた財宝：

- **CR 0-4**: 50-100金貨 +  modest magic item (0-2)
- **CR 5-10**: 500-2,000金貨 +  moderately powerful magic item (1-2)
- **CR 11-16**: 5,000-20,000金貨 +  rare magic item (1)
- **CR 17+**: 50,000+金貨 +  legendary item (1)

戦利品はGMが調整可能。
