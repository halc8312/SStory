# コアメカニクス - エターナル・アルカディアTRPG

## 1. 基本概念

エターナル・アルカディアTRPG（以下EATRPG）は、**d20+修正値 vs DC**のシンプルなダイスシステムを採用している。世界観の魔法システム「精霊契約」と完全に連動しており、種族や魔法の特性がゲームバランスに反映される。

### 1.1 ダイス

- **d20**: 主要判定（攻撃、技能、セービングスロー）
- **d6**: ダメージダイス、 randomization
- **d4, d8, d10, d12**: 特殊な能力や武器で使用

### 1.2 能力値 (Ability Scores)

6つの基本能力値：

| 略称 | 日本語 | 説明 | 主に影響するスキル |
|------|--------|------|-------------------|
| STR  | 筋力 | 物理攻撃力、持ち運び容量 | 近接攻撃、重量 |
| DEX  | 敏捷性 | 回避、先制、遠隔攻撃 | AC、先制、隠密 |
| CON  | 耐久力 | HP、耐病、持久力 | HP、 stamina |
| INT  | 知力 | 魔法学、知識、解析 | 魔法威力、スキル数 |
| WIS  | wisdom | 知覚、精神、直感 | 感知、精神攻撃耐性 |
| CHA  | 魅力 | 交渉、精霊契約、リーダーシップ | 交渉、精霊契約度 |

**初期値**: 各能力値は 10 から開始。種族修正を適用。

**能力値修正 (Ability Modifier)**:
```
修正値 = (能力値 - 10) / 2 (小数点以下切捨て)
```
例: STR 16 → +3, DEX 8 → -1, CON 12 → +1

### 1.3 種族修正 (Racial Modifiers)

| 種族 | STR | DEX | CON | INT | WIS | CHA | 精霊契約 |
|------|-----|-----|-----|-----|-----|-----|----------|
| 人間 | +0 | +0 | +0 | +1 | +0 | +1 | バランス (全元素+5%) |
| エルフ | -1 | +2 | -1 | +1 | +1 | +0 | 風 +15% |
| ドワーフ | +2 | -1 | +2 | +0 | +0 | -1 | 地 +15% |
| オーク | +2 | -1 | +1 | -1 | +0 | +1 | 火 +15% |
| ハーフリング | -2 | +2 | +1 | +0 | +1 | +1 | 水 +15% |

**精霊契約度**: 種族ごとのベース契約度。追加で個人変動あり (±5%)。

### 1.4 年齢による能力変化

| 種族 | 幼年期 | 成年 | 老年 | 平均寿命 |
|------|--------|------|------|----------|
| 人間 | 0-15歳 | 16-60歳 | 61-80歳 | 80年 |
| エルフ | 0-50歳 | 51-300歳 | 301-500歳 | 500年 |
| ドワーフ | 0-40歳 | 41-250歳 | 251-400歳 | 400年 |
| オーク | 0-12歳 | 13-50歳 | 51-70歳 | 70年 |
| ハーフリング | 0-10歳 | 11-80歳 | 81-100歳 | 100年 |

年齢による修正: 老年で STR/CON -2, INT/WIS +2 など（必要に応じて）。

## 2. 判定システム (Resolution System)

### 2.1 基本判定

**手順**:
1. GMが難易度 (DC) を設定 (通常 10-30)
2. プレイヤーが d20 を振る + 関連能力修正 + スキル修正 + その他ボーナス
3. 合計が DC 以上なら成功

**例**: 開錠 (DEX+細工技能) DC15。DEX修正+2、スキル+4 → d20+6 vs 15。

### 2.2 攻撃判定

**命中判定**:
```
d20 + 攻撃ボーナス (STR or DEX) + 武器 Proficiency + その他 >= 目標AC
```

- **近接武器**: STRベース
- **遠隔武器**: DEXベース
- **魔法攻撃**: INT ( Mage ) or WIS ( Priest ) or CHA ( Warlock )

**クリティカル**: 自然20 (d20で1) は自動命中かつダメージ2倍。自然1は自動ミス。

### 2.3 セービングスロー (Saving Throw)

** target **が効果から逃れるための判定。

**形式**: d20 + 能力修正 +  proficiency (あれば) + その他 vs DC

**主要セービングスロー**:
- **STR save**: 物理的圧力、押し戻し
- **DEX save**: 範囲効果、爆発、トラップ
- **CON save**: 毒、病、疲労
- **INT save**: 幻覚、精神操作、論理罠
- **WIS save**: 恐怖、魅了、呪い
- **CHA save**: 魅了、支配、精霊の干渉

### 2.4 スキルチェック

各キャラクターは背景とクラスに応じてスキルを選択。

**スキル一覧** (後述 `character-creation.md` に完全リスト)

**スキル修正**: 能力修正 + 訓練ボーナス (Proficiency) + 装備ボーナス

## 3. 戦闘システム (Combat)

 combatシステムの詳細は `combat.md` を参照。

ここでは簡潔に:

- **イニシアチブ**: DEXチェックで順番決定
- **ターン**: 1ターン = 6秒
- **行動**: 1標準行動 + 1移動行動 + 1フリーアクション
- **アクション economy**: 攻撃、魔法、アイテム使用、ダッシュ、Disengage, Dodge, Help, Hide, Ready など

## 4. 魔法システム (Magic)

詳細は `magic-casting.md` を参照。

**基本**:
- 魔法は **Rank D から S+** まで段階
- **MP (Mana Points)** を消費
- **詠唱時間**、**成分** (V/S/M)、**持続時間**、**範囲** を定義
- **成功判定**: 呪文セービングスロー or 攻撃ロール

## 5. ダメージと治癒

### 5.1 ダメージタイプ

| タイプ | 例 | 特徴 |
|--------|----|------|
| 物理 | 切り裂き、刺突、殴打 | 一般的、耐性多い |
| 火 | ファイアーボール | 可燃物に有効 |
| 水 | ウォーター・ジェット | 火弱点 |
| 風 | ウィンド・カッター | 軽量 |
| 地 | ロック・スロー | 重防御 |
| 月 | ルナ・ブラスト | 神秘 |
| 電撃 | ライトニング・ボルト | 速攻 |
| 冷気 | アイス・シャード | 遅延 |
| 毒 | ポイズン | 継続ダメージ |
| 精神 | マインド・パニック | 意志セービング |

### 5.2 ダメージ計算

**通常**: 武器/呪文のベースダメージ + 能力修正 (STR or DEX or casting ability)

例: ロングソード (1d8) + STR (+3) = 1d8+3

**クリティカル**: ダメージダイスを2倍 (修正値はそのまま)

### 5.3 治癒

- **ヒール**: 治癒魔法でHP回復 (上限は最大HP)
- **休息**: 8時間睡眠でHPの半分 + CON修正 × レベル
- **ポーション**: アイテムで即時回復

## 6. 経験値とレベルアップ (Progression)

### 6.1 経験値テーブル

| レベル | 必要XP | ボーナス |
|--------|--------|----------|
| 1 | 0 | - |
| 2 | 300 | +1 スキル |
| 3 | 900 | +1 能力値 (任意2) |
| 4 | 2,700 | +1 スキル |
| 5 | 6,500 | +1 能力値 |
| 6 | 14,000 | +1 スキル |
| 7 | 23,000 | +1 能力値 |
| 8 | 36,000 | +1 スキル |
| 9 | 52,000 | +1 能力値 |
| 10 | 76,000 | +1 スキル (max) |

**最大レベル**: 10 (物語の上限)。必要に応じて拡張可。

### 6.2 レベルアップ時の向上

- **HP**: クラスのヒットダイス + CON修正 (毎レベル)
- **スキル**: 指定されたスキルを1つ選択して+1（最大値: レベル+3）
- **能力値**: レベル3,5,7,9 で任意の能力2つを+1（最大20）
- **呪文**: 魔法使いクラスは新呪文を取得

## 7. 状態異常 (Conditions)

| 状態 | 効果 | 解除方法 |
|------|------|----------|
| **Blinded (盲目)** | 視覚不能、攻撃ロール不利、防御無効 | 治癒魔法 |
| **Charmed (魅了)** | 魅了した存在を攻撃できない | 魅了解除 |
| **Deafened (聴覚不能)** | 聴覚不能、音に基づく判定不利 | 治癒魔法 |
| **Frightened (恐怖)** | 恐怖源から逃げる、判定不利 | 恐怖解除 |
| **Grappled (組み付き)** | 移動不能、速度0 | 脱出判定 (STR/DEX) |
| **Incapacitated (無力)** | 行動不能 | 全治癒 |
| **Invisible (不可視)** | 攻撃ロール不利、防御有利 | 真実の視線 |
| **Paralyzed (麻痺)** | 行動不能、自動失敗 | 強力治癒 |
| **Petrified (石化)** | 完全行動不能、無敵だが無防備 | 石化解除 |
| **Poisoned (中毒)** | 攻撃ロールとセービング不利 | 中和毒 |
| **Prone (倒れ)** | 移動不能、近接攻撃ロール不利、遠隔攻撃ロール不利 | 起き上がり行動 |
| **Restrained (拘束)** | 速度0、移動不可、攻撃ロール不利、防御不利 | 脱出判定 |
| **Stunned (スタン)** | 自動失敗、次ターン自動失敗 | 短い休息 |
| **Unconscious (意識不明)** | 自動失敗、自动失敗、HP0で dying | 安定化チェック |

## 8. 休息と回復

### 8.1 短い休息 (Short Rest)

**時間**: 1時間以上、8時間未満
**効果**:
- ヒットダイスを振ってHP回復 (1回/レベル)
- 一部クラスの能力回復 (例: 戦士の疲労回復)

### 8.2 長い休息 (Long Rest)

**時間**: 8時間以上 (睡眠含む)
**効果**:
- HP全回復
- ヒットダイス全回復 (半分以上回復)
- MP全回復
- 消耗した能力回復

**制限**: 24時間に1回まで

|------|----|------|---------|-----------------|

**遠隔**:
- ショートボウ (1d6, 機敏)

**所持重量 (Encumbrance)**:
- 強さ (STR) × 15 ポンドまで無制限

## 10. マルチクラス (Multiclass)

**許可**: 可 (ただし、クラス間でシナジー必要)

**ルール**:
- レベルアップ時に別クラスを選択可能
- 各クラスのヒットダイス、スキル、能力は個別に計算
- プロフィッシェンシー (Proficiency) は各クラス別に計算

**推奨**: 2-3クラスまで、バランスを考慮

---

## 11. 精霊契約のゲーム内効果

### 11.1 契約度によるボーナス

各種族には種族ベースの契約度 (例: エルフ 風 75%)。この値が高いほど精霊魔法の成功率と威力が向上。

**ボーナス計算**:
- 魔法成功率: `50% + 契約度%`
- 魔法威力: `基本威力 × (1 + 契約度% × 0.2)` (最大+50%)
- 精霊召喚: 契約度が70%以上で可能

### 11.2 個人契約度

個々のキャラクターは追加で契約度を獲得可能（最大種族MAX+10%）。修行やイベントで向上。
