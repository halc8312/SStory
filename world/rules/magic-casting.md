# 魔法発動ルール - エターナル・アルカディア

## 1. 魔法の基本

魔法は**精霊との契約**に基づき、5大元素（風、地、火、水、月）の力を借りて発動します。

### 1.1 魔法ランク

| ランク | 名称 | 呪文レベル | 説明 |
|--------|------|------------|------|
| Forbidden | 禁忌 | 7 | 世界を揺るがす極大魔法 |
| S+ | 特級 | 6 | 大陸規模の効果 |
| S | 上級 | 5 | 都市规模の破壊/治愈 |
| A | 上級 | 4 | 大規模な効果 |
| B | 中級 | 3 | 小队规模の戦闈 |
| C | 初級 | 2 | 小規模な効果 |
| D | 基礎 | 1 | 日常生活レベル |
| Cantrip | 特技 | 0 | 常時発動可能な微小魔法 |

### 1.2 元素系統

- **風 (Wind)**: 移動、通信、切断
- **地 (Earth)**: 防御、建設、重力
- **火 (Fire)**: 破壊、加熱、光
- **水 (Water)**: 治癒、凍結、流動
- **月 (Moon)**: 精神、時間、幻覚

## 2. 呪文発動の手順

### 2.1 呪文の準備

魔導士は毎日、**呪文の準備**を行う (1時間の冥想)。

- **準備可能数** = クラスレベル + 能力修正 + その他ボーナス。
- 準備した呪文のみがその日使用可能。
- Cantrip (特技) は常時使用可能。

### 2.2 詠唱時間 (Casting Time)

- **1アクション**: 標準的な呪文 (戦闘中)。
- **1ボーナスアクション**: 短い呪文。
- **1分～数分**: 短時間の集中。
- **10分～1時間**: 儀式魔法 (儀式)。
- **数時間～数日**: 大規模魔法。

### 2.3 成分 (Components)

すべての呪文には成分が必要：

- **V (Verbal)**: 呪文の唱え (言葉)。沈黛状態では不可能。
- **S (Somatic)**: 身振り手振り。手が塞がっていると困難。
- **M (Material)**: 素材アイテム。特殊な材料が必要な呪文あり。

**成分省略**:
-  featやアイテムで一部省略可能。
- 一部呪文はV/S不要 (テレパシーなど)。

### 2.4 呪文スロット (Spell Slots)

クラスレベルに応じた1日あたりの使用可能回数。

| クラスレベル | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|--------------|---|---|---|---|---|---|---|
| 1 | 2 | - | - | - | - | - | - |
| 2 | 3 | - | - | - | - | - | - |
| 3 | 4 | 2 | - | - | - | - | - |
| 4 | 4 | 3 | - | - | - | - | - |
| 5 | 4 | 3 | 2 | - | - | - | - |
| ... | ... | ... | ... | ... | ... | ... | ... |
| 10 | 4 | 3 | 3 | 3 | 2 | - | - |
| 15 | 4 | 3 | 3 | 3 | 3 | 2 | - |
| 20 | 4 | 3 | 3 | 3 | 3 | 2 | 1 |

*各レベルに対応するランク: 1=D, 2=C, 3=B, 4=A, 5=S, 6=S+, 7=Forbidden.

### 2.5 呪文判定 (呪文発動判定)

敵がセーブを行う場合：

`DC = 8 + 呪文レベル + 呪文能力修正 (INT/WIS/CHA) + プロフィットボーナス`

目標は `d20 + セーブ修正` でDCを上回れば半減/無効。

**例**: DC15のセーブ、目標がd18+2=20 → 成功 (半ダメージまたは無効)。

### 2.6 呪文攻撃ロール (Spell Attack)

`d20 + 呪文攻撃ボーナス (能力修正 + プロフィット) vs 目標のAC`

## 3. 精霊契約と魔法

### 3.1 契約度の影響

各元素魔法を使用するには、その元素の精霊との契約度が必要。

**成功率計算**:
- 基礎成功率 = 契約度%
- 追加ボーナス: 契約度80%以上で判定+2、90%以上で+5。

**失敗時の反動**:
- 契約度30%未満: 50%で反動 (呪文失敗 + 疲労)
- 契約度30-60%: 25%で反動
- 契約度60%以上: 5%で反動

### 3.2 精霊の加護

高い契約度で得られる特典：

- 60%以上: 元素ダメージ+1段階 (例: 1d6→1d8)
- 75%以上: 成分 (V/S/M) 1つ省略可能
- 90%以上: 毎日1回、自動成功 (1回/日)

## 4. 魔力と疲労

### 4.1 魔力ポイント (MP) 代替案

クラスベースのスロット方式を採用。ただし、強力な呪文連続使用で**疲労**が蓄積。

**疲労ルール**:
- 1日にSランク以上の呪文を3回以上使用 → 疲労1 (CONセーブ DC15 で回避)
- 疲労: 全能力値 -2、速度半減。短休憩で軽減 (1レベル)。
- 疲労3で倒れ、長休憩が必要。

### 4.2 魔力回復

- 短休憩: 使用済みスロットの合計レベル分のヒールダイスで回復可能。
- 長休憩: 全回復。

## 5. 呪文の例

### 5.1 火炎弾 (Fire Bolt) - Cランク (2nd level)

- **成分**: V, S
- **詠唱時間**: 1アクション
- **範囲**: 120フィート, 1目標
- **効果**: `2d10` 火炎ダメージ。目標はDEXセーブ (DC13) で半減。
- **契約要求**: 火の精霊 契約度 ≥ 30%

### 5.2 治癒の光 (Healing Light) - Cランク (2nd level)

- **成分**: V, S
- **詠唱時間**: 1アクション
- **範囲**: 触れた生物1体
- **効果**: `2d8+5` HP回復。不死・構築物は無効。
- **契約要求**: 水の精霊 契約度 ≥ 40%

### 5.3 風の翼 (Wind Wings) - Bランク (3rd level)

- **成分**: V, S, M (羽根1枚)
- **詠唱時間**: 1分
- **効果**: 自身または触れた生物1体に飛行能力 (速度30フィート) を10分間付与。
- **契約要求**: 風の精霊 契約度 ≥ 50%

### 5.4 地の壁 (Earth Wall) - Bランク (3rd level)

- **成分**: V, S, M (小石5つ)
- **詠唱時間**: 1アクション
- **効果**: 20フィート立方の石壁を生成、AC15、HP50。10分持続または破壊。
- **契約要求**: 地の精霊 契約度 ≥ 50%

### 5.5 月の幻影 (Moon Phantasm) - Aランク (4th level)

- **成分**: V, S
- **詠唱時間**: 1アクション
- **範囲**: 60フィート 球形容器
- **効果**: 範囲内の全敵に WISセーブ (DC15) 失敗 → 混乱 (1ラウンド) + 魅了 (1分)。
- **契約要求**: 月の精霊 契約度 ≥ 70%

## 6. 呪文の構成要素

### 6.1 ダメージ計算

`基本ダイス + 能力修正 + その他ボーナス`

例: Fire Bolt (2d10) + INT修正 (+3) = 2d10+3.

### 6.2 セーブDC

`8 + 呪文レベル + 呪文能力修正 + その他ボーナス`

例: 3rd level spell, INT +4 → DC = 8+3+4 = 15.

### 6.3 範囲と標的

- **自己**: 自分 only
- **触れる**: 自身か触れた生物/物
- **60フィート 円錐**: 扇形範囲
- **球**: 半径X フィート の球体
- **直線**: 長さX フィート の線

## 7. 高位魔法のリスク

### 7.1 禁忌魔法 (Forbidden)

- 使用には **GM許可** 必須。
- 使用後、キャラクターに**永続的欠落**または**呪い**が発生。
- 毎使用で **契約度 -10%** のペナルティ。
- 社会から追放や冒険者ギルド追放のリスク。

### 7.2 過剰使用のペナルティ

- **1日3回以上のS+ランク呪文**: 疲労1、CONセーブ (DC20) で疲労軽減。
- **1日5回以上のSランク**: 自動疲労1、追加で能力値1つ-2 (24時間)。
- **Forbidden使用**: 即座に疲労2、契約度20%減少、1週間の呪文使用不可。

## 8. 反魔法と対抗

### 8.1 魔法耐性 (Magic Resistance)

一部種族/モンスターは魔法セーブにadvantage。

### 8.2 反魔法フィールド (Anti-Magic Field)

- エリア内のすべての魔法を無効化。
- 既存の魔法効果は一時停止。
- 精霊契約も機能しない。

### 8.3 カウンタースペル (Counterspell)

- 他者が詠唱中に反応で使用。
- 判定: 呪文レベル vs 呪文能力チェック (d20+能力+プロフィット)。

## 9. 精霊召喚 (Summoning)

### 9.1 召喚ルール

- 精霊と契約度が高いほど強力な精霊を召喚可能。
- 召喚には素材 (M成分) と長時間の儀式が必要な場合が多い。
- 召喚された精霊は独自AI (GM管理) で行動。

### 9.2 召喚例

- **風の精霊シルフ**: 契約度50%以上、3ラウンド行動、風ダメージ。
- **地の精霊ゴーレム**: 契約度70%以上、守護、高AC。
- **火の精霊イフリート**: 契約度80%以上、大火炎攻撃。
- **水の精霊ウンディーネ**: 契約度60%以上、治癒支援。
- **月の精霊ルナ**: 契約度90%以上、幻覚・時間操作。

## 10. 魔法の学習と訓練

### 10.1 魔法学校

- **初等魔法学校** (6～12歳): 基礎教育、Cantrip習得。
- **中等魔法学院** (13～18歳): 元素別专科選択。
- **高等魔法大学** (19歳～): 研究、Aランク以上習得可能。

### 10.2 自己学習

- 契約度上げにより、上位ランクの呪文を独学で習得可能 (GM裁量)。
- 古代遺跡や魔導書から学習。
