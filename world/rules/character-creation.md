## 2. 種族 (Race)

**能力修正**:
- STR +0, DEX +0, CON +0, INT +1, WIS +0, CHA +1
**精霊契約**: バランス型 (全元素 +5%)
**速度**: 30 ft
**サイズ**: Medium
**寿命**: 80年

**特徴**: 適応力高、汎用。あらゆるクラスに適する。

**速度**: 35 ft
**サイズ**: Medium
**寿命**: 500年

**特徴**:
-  darkvision 60ft

- 自然との親和性高

### 2.3 ドワーフ (Dwarf)

**寿命**: 400年

- darkvision 60ft

## 3. クラス (Class)

各クラスは **ヒットダイス**、**主要能力**、**特徴**を持つ。

### 3.1 戦士 (Fighter)

**ヒットダイス**: d10
**主要能力**: STR or DEX, CON
**特徴**:
- 戦闘技巧: extra attack (Lv5)
- 防護スタンス: AC+1 (optional)
- 第二精力: 1/戦闘

**典型的な役割**: 前衛、盾役、高耐久

### 3.2 魔法使い (Mage)

**ヒットダイス**: d6
**主要能力**: INT (primary), DEX, CON
**特徴**:
- 呪文 casting (INTベース)
- arcane recovery: 短い休息でMP一部回復
- スペルブック: 呪文収集

**サブクラス** (Lv2選択):
- **Evoker** (攻撃特化)
- **Abjurer** (防御特化)
- **Diviner** (予言・支援)
- **Conjurer** (召喚)
- **Enchanter** (魅了)

**典型的な役割**: 後衛、範囲魔法、支援

### 3.3 盗賊 (Rogue)

**ヒットダイス**: d8
**主要能力**: DEX (primary), INT, CHA
**特徴**:
- expertise: 2技能に倍修正
- sneak attack: 位置有利で1d6 (Lv1) → Lv11で5d6
- evasion: DEX save 成功で半ダメージ → 無効

**サブクラス**:
- **Thief** (器用さ)
- **Assassin** (暗殺)
- **Arcane Trickster** (軽い魔法)

**典型的な役割**: 隠密、罠解除、単体高ダメージ

### 3.4 牧師 (Cleric)

**ヒットダイス**: d8
**主要能力**: WIS (primary), CON, CHA
**特徴**:
- 呪文 casting (WISベース、治癒・防御中心)
- channel divinity: 1/休憩 (特殊能力)
- domain (Lv1) で専門化

**ドメイン例**:
- **Life**: 治癒特化
- **Light**: 攻撃魔法
- **War**: 近接戦闘支援
- **Nature**: 自然との絆
- **Tempest**: 嵐の力

**典型的な役割**: ヒーラー、支援、時折前衛

### 3.5 レンジャー (Ranger)

**ヒットダイス**: d10
**主要能力**: DEX, WIS (primary)
**特徴**:
- 自然探索: 追踪、生存に優れる
- ファイバー・アーチャー: 二重攻撃 (Lv5)
-  favor of the wild: 自然の加護

**典型的な役割**: 偵察、遠隔攻撃、自然環境生存

### 3.6 パラディン (Paladin)

**ヒットダイス**: d10
**主要能力**: STR, CHA (primary)
**特徴**:
- 聖なる力: 治癒・防御魔法
- divine smite: 攻撃時にMP消費で追加ダメージ
- auras: 味方強化 (Lv6,10,15,18)

** oath ** (Lv3):
- **Devotion**: 清廉
- **Vengeance**: 復讐
- **Ancients**: 古の自然守護

**典型的な役割**: 前衛、リーダー、ヒーラー補助

## 4. 能力値決定方法

### 4.1 標準 (Standard)

4d6を6回振り、各能力に割り当て ( highest to lowest or custom).

例: 4d6 drop lowest → [15,14,13,12,10,8] → STR15, DEX14, CON13, INT12, WIS10, CHA8

### 4.2 阶级 (Point Buy)

27ポイントを6能力に分配 (最小8, 最大15 before racial).

コスト表:
- 8: 0 pt
- 9: 1 pt
- 10: 2 pt
- 11: 3 pt
- 12: 4 pt
- 13: 5 pt
- 14: 7 pt
- 15: 9 pt

### 4.3 ロール (Rolling)

3d6 ×6 (低め、ハードコア)

## 5. スキル (Skills)

各能力に紐づくスキル:

| 能力 | スキル | 説明 |
|------|--------|------|
| STR | Athletics | 筋力競技、登攀、組み付き |
| DEX | Acrobatics | 体操、バランス、転倒回避 |
| DEX | Sleight of Hand | 手品、細工 |
| DEX | Stealth | 隠密、追跡回避 |
| INT | Arcana | 魔法学、超自然 |
| INT | History | 歴史、考古学 |
| INT | Investigation | 調査、推理 |
| INT | Nature | 自然、生態 |
| INT | Religion | 宗教、神々 |
| INT | Engineering (optional) | 機械、建築 |
| WIS | Animal Handling | 動物との交流 |
| WIS | Insight | 感情読取、嘘 detection |
| WIS | Medicine | 治療、応急処置 |
| WIS | Perception | 観察、気付く |
| WIS | Survival | 生存、追跡 |
| CHA | Deception | 欺瞞、嘘 |
| CHA | Intimidation | 脅迫、威圧 |
| CHA | Performance | 演技、芸能 |
| CHA | Persuasion | 交渉、説得 |

**スキル選択**:
- クラスで許可されたスキルから 数種 (通常3-4) をtraining (Proficiency) として選択
- Training があると ability修正 + proficiency bonus (レベル依存) を加算

**Proficiency Bonus**:
| レベル | ボーナス |
|--------|---------|
| 1-4 | +2 |
| 5-8 | +3 |
| 9-12 | +4 |
| 13-16 | +5 |
| 17-20 | +6 |

## 7. 精霊契約の設定

### 7.1 契約種族ごとのベース契約度

| 種族 | 契約元素 | ベース% | 最大% |
|------|----------|---------|-------|
| 人間 | 全元素 (バランス) | 5% each | 30% each |
| エルフ | 風 | 15% | 75% |
| ドワーフ | 地 | 15% | 75% |
| オーク | 火 | 15% | 75% |
| ハーフリング | 水 | 15% | 75% |

### 7.2 個人契約度の決定

ベース + 1d10% (ランダム) または 背景ボーナスで決定。

例: エルフの場合 15% + 1d10 (1-10) → 16-25% 開始。

### 7.3 契約度の上昇

- **修行**: 1週間の修行で +1% (年1回まで)
- **試練**: 精霊との試練クリアで +5-10%
- **クエスト報酬**: +5%
- **年齢**: 每年 +0.1%

**最大**: 種族最大値 (例: エルフ 風 75%)。それ以上は精霊王クラスのみ。

## 8. 背景 (Background)

背景は技能と初期装備、社会的位置を提供。

### 8.1 代表的な背景

- **学者 (Scholar)**: 歴史・宗教技能, 本と筆記具
- **交易商人 (Merchant)**: 交渉・評価技能, 商売道具
- **軍人 (Soldier)**: 運動・ intimidation, 武器防具
- **職人 (Craftsperson)**: 細工・生存, 工具
- **盗賊 (Urchin)**: 隠密・ sleight of hand, 泥棒道具
- **聖職者 (Acolyte)**: 宗教・交渉, 聖典・徽章
- **放浪者 (Outlander)**: 生存・動物 handling, 旅道具

**利点**: 背景技能にproficiency、初期装備、最初のつながり。

## 10. 作成例

### 例1: エルフの魔法使い (Elf Mage)

**種族**: エルフ
**クラス**: Mage (Lv1)
**背景**: Scholar

- STR 8 (-1), DEX 14 (+2), CON 12 (+1), INT 15 (+2), WIS 10 (+0), CHA 10 (+0)

**呪文** (Lv1 slots: 2):
- 攻撃: Magic Missile (1d4+1 ×3)
- 防御: Shield (reaction, +5 AC)
- 支援: Mage Armor (AC13, 8h)

## 11. レベルアップ時

各レベルで:
- HP: ヒットダイス + CON修正 を追加
- プロフィッシェンシー: +1 (特定のレベルで)
- 能力値向上: レベル3,5,7,9 で任意2能力+1 (最大20)
- クラス特徴: クラスごとの新能力獲得
- スキル: クラスに応じて追加スキル訓練可能 (最大: レベル+3)

---

## 12. _multiclass_ ルール

別クラスに進む場合:
- 各クラスのヒットダイス、技能、クラス特征是別に計算
- 攻撃ボーナス、セービングスローはクラスごとに別々 (最高値を使用しない)
- Proficiency bonus は total character level で統一

例: Fighter 3 / Mage 2 → 合計レベル5 → proficiency +3
