# 高精細地図スタイル仕様

## 方向性

基調は既存の古地図ですが、情報設計は現代の地図アプリに寄せます。

- 北が上の厳密な平面地図
- セピアの紙質、細いインク線、控えめな地形色
- 海はくすんだ青、森林はオリーブ、砂漠は赤褐色、氷雪は灰青
- 山、樹木、街並みは縮尺に応じて密度を増やす
- ラスタ画像内に文字、数字、凡例、方位記号、装飾枠を入れない
- 光源、陰影方向、線幅、紙の粒度を隣接画像で統一する

## 画風の不変条件

- 厳密な真上視点とし、鳥瞰図や遠近法へ変えない
- 海岸線、河川、道路、城壁、街区外周を制御図から移動しない
- 正典にない主要都市、港、橋、塔、遺跡を追加しない
- 自動車、舗装道路、電柱、近代的な船舶などを混入させない
- 読める文字、偽文字、署名、透かしを含めない
- 大きな樹木、建物、岩を機械的に反復しない

## 縮尺別の情報量

| 階層 | 新しく見せる情報 |
| --- | --- |
| 世界 | 五大陸、主要海域、巨大山系、主要都市の象徴 |
| 大陸 | 地域境界、主要河川、主要街道、港、浮島群 |
| 地域 | 支流、地方道、集落、農地、森林の内部構造 |
| 都市 | 城壁、地区、幹線道路、橋、運河、港湾施設 |
| 街区 | 建物群、路地、広場、門、庭園、埠頭 |

下位階層を縮小したときは、親階層の海岸線、山系、森林帯、主要道路と一致して見える必要があります。

## ベクター表示

- 日本語を標準ラベルとし、英語名は地名辞書に別名として保持する
- ラベルはズームと重要度に応じて段階表示する
- 道路、鉄道、海路、空路、危険区域、POI は独立レイヤーとする
- 文字は背景とのコントラストを確保し、拡大しても鮮明に表示する
- `canon`、`estimated`、`draft` を表示上で区別できるようにする

## 初期画風候補

1. 既存継承: 装飾を除いた既存世界図に最も近い画風
2. 高可読: 線と色面を整理し、地形判別を強めた画風
3. 精密銅版: 細密な線刻と抑えた色で高倍率の情報量を増やす画風

同じ制御図から候補を作り、Vision QA で順位付けした後にゴールデンスタイルを固定します。
