GitHub Pages の公開元でも、正典資料の編集先でもありません。

- 現行の公開サイト: [`../docs/`](../docs/)
- 正典資料: [`../world/`](../world/)
- 公開URL: <https://halc8312.github.io/SStory/>

通常のサイト修正は `docs/` に行ってください。このディレクトリを再び公開候補に
戻す場合は、現行サイトとの統合方針を決め、リンクと内容を再監査してください。
