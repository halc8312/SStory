# 地図ギャラリー

エターナル・アルカディアの各種地図を紹介します。

## 地図コレクション

### 🌍 世界地図

**世界全体の俯瞰図**。五大陸と主要海域、浮島群を一覧できます。

- **スケール**: 1:50,000,000
- **掲載情報**:
  - 五大陸の位置と形
  - 主要国家の境界
  - 主要都市の位置
  - 主要航路・街道
  - 山脈・河川・海域

**ファイル形式**: SVG / PNG (高解像度版は後日追加予定)

## 地図の利用方法

### 閲覧方法

1. **オンライン閲覧**: 本サイトで各画像をクリックして拡大表示
2. **ダウンロード**: 高解像度版はリポジトリからダウンロード可能
3. **印刷用PDF**: 後日提供予定

### 利用規約

地図画像は **CC BY-SA 4.0** に基づき利用可能です。

- クレジット表示: `出典: SStory / エターナル・アルカディア世界構築プロジェクト`
- 改変・商用利用: OK
- 継承義務: あり

## 地図画像の保存場所

完成した地図画像は以下のリポジトリパスに保存されます：

```
world/maps/
├── world-map.svg               # 世界地図（ベクター）
├── world-map.png               # 世界地図（高解像度）
├── continents/
│   ├── elysion-map.png         # エリュシオン
│   ├── lumiera-map.png         # リュミエラ
│   ├── chaos-realm-map.png     # カオス・リア
│   ├── atlantis-map.png        # アトランティス
│   └── grimoire-map.png        # グリモワール
├── regions/
│   ├── central-region.png      # 中央地域
│   ├── eastern-region.png      # 東地域
│   ├── southern-region.png     # 南地域
│   ├── western-region.png      # 西地域
│   └── northern-region.png     # 北地域
├── transport/
│   ├── road-network.png        # 街道網
│   ├── sea-routes.png          # 航路
│   ├── air-routes.png          # 空路
│   └── public-transport.png    # 公共交通
└── gallery/
    └── (ギャラリー表示用サムネイル)
```
