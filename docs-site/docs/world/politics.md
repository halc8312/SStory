# 政治・国家

エターナル・アルカディアの政治体制と主要国家を紹介します。

## 世界の政治体制

エターナル・アルカディアは、**十二国同盟**を基軸とする**多極化世界**です。

### 統治体制の特徴

1. **十二大国**: 世界を代表する主要国家
2. **同盟体制**: 十二国同盟条約に基づく平和協調
3. **自治権**: 各地域・種族の自治を尊重
4. **国際機関**: 時空番人会、元素寺院連合など

## 国際機関・特殊組織

### 時空番人会（Chrono Guard）

- グリモワールを管理する特殊機関
- 時空魔法と禁忌知識の管理・監視
- 十二国同盟から独立した権限

### 元素寺院連合（Elemental Temples）

- 五元素精霊への信仰組織
- 魔法使いの認定と管理
- 精霊関連問題への対応

### 十二国同盟（Twelve Nations Alliance）

- 主要12国による政治経済同盟
- 平和条約、貿易協定、移民協定を管理
- 年1回の首脳会議開催

## 国際関係

### 主要同盟・条約

1. **十二国同盟条約**（約200年前）
   - 平和条約、相互不可侵
   - 貿易協定、移民協定
   - 外交優先の原則

2. **元素協定**
   - 精霊との関係維持
   - 魔法使用の共通ルール

3. **時空管理協定**
   - 時空魔法の管理と監視
   - 禁忌技術の封印

### 懸念事項

- **グリモワール問題**: 時空番人会の過剰権力
- **海賊問題**: 南西海域の安全保障
- **種族間不均衡**: 長寿種族と短命種族の政策時間軸の違い
- **資源争奪**: 特定資源（希少鉱物、神秘作物）を巡る競争

## 今後の政治的展開

- 十二国同盟の強化・拡大（将来的に其他国家も参加の可能性）
- 国際法の整備
- 宇宙・異世界への法的対応（将来の拡張に備え）
