# 地理

エターナル・アルカディアの地理情報を紹介します。

## 世界の構成

エターナル・アルカディアは、**五つの主要大陸**と**無数の浮島**から構成されています。

```
主要大陸:
1. エリュシオン（中央大陸） - 政治経済の中心
2. リュミエラ（東大陸） - 神秘と月魔法の大地
3. カオス・リア（南大陸） - 砂漠と炎の大地
4. アトランティス（西大陸） - 氷と海の大陸
5. グリモワール（北大陸） - 時空と禁忌の大地
```

## 大陸ごとの概要

### 🌍 エリュシオン（中央大陸）

- **首都**: アストラリス（ゼフィア連合共和国）
- **主要都市**: ゼフィア、リュミエラ、カオス・リア
- **特徴**:
  - 世界の政治・経済の中心
  - 最も発達した都市群
  - 主要な魔法学院が集積
- **気候**: 温暖湿潤、四季がある

---

### 🌙 リュミエラ（東大陸）

- **統治**: 月影エルフ王国
- **主要都市**: ムーンフォール、エルフハイム
- **特徴**:
  - 月魔法の発祥地
  - エルフ文化の中心
  - 神秘的な遺跡が多数
- **気候**: 亜熱帯、多湿

---

### 🔥 カオス・リア（南大陸）

- **統治**: 赤砂オーク連合
- **主要都市**: ファイアベース、砂嵐砦
- **特徴**:
  - 広大な砂漠地帯
  - 炎魔法の伝統
  - 遊牧文化が主流
- **気候**: 砂漠気候、昼夜の気温差大

---

### ❄️ アトランティス（西大陸）

- **統治**: アトランティス女王領
- **主要都市**: パールシティ、氷晶宮
- **特徴**:
  - 海洋国家群
  - 水・氷魔法の名手
  - 潜水技術が発達
- **気候**: 冷涼湿潤、多雨

---

### ⏳ グリモワール（北大陸）

- **統治**: 時空番人会（特殊機関）
- **主要都市**: クロノポリス、時空塔
- **特徴**:
  - 時空魔法の研究拠点
  - 禁忌の知識が集積
  - 時間の流れが不安定な地域あり
- **気候**: 寒帯、極寒

---

この世界の地理情報は、**Map Data**としてJSON形式で管理されています。

- **nodes.json**: 都市、村、拠点、天然 phenomena などの地点データ

- **hazards.json**: 危険区域（モンスター棲息地、災害危険地帯など）
- **continents.json**: 大陸のメタデータ
- **regions.json**: 地域のメタデータ
