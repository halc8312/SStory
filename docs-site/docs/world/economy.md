# 経済

エターナル・アルカディアの経済システムを紹介します。

## 世界経済の概要

エターナル・アルカディアでは、**魔導技術と魔法が融合した独特の経済体系**が築かれています。

### 主要特徴

1. **多通貨体制**: 各国ごとの通貨＋国際標準通貨
2. **交易圏**: 十二国同盟による広大な自由貿易圏
3. **資源配分**: 大陸ごとの特色を活かした分業
4. **技術格差**: 魔導技術の普及度に地域差あり

## 通貨システム

### 国際標準通貨

十二国同盟で公式に認められている国際通貨：

| 通貨名 | 発行国 | 価値 | 特徴 |
|--------|--------|------|------|
| **アストラ（金貨）** | ゼフィア連合共和国 | 基準通貨 | 金地金-backed、国際決済で使用 |
| **ムーン（銀貨）** | 月影エルフ王国 | 1/10アストラ | 月魔法で保護された貨幣 |
| **グリム（銅貨）** | グリモワール（時空番人会） | 1/100アストラ | 時空技術で偽造防止 |

### 各国独自通貨

各国でも独自通貨を発行していますが、十二国同盟内では**アストラが標準**として広く受け入れられています。

**為替レート例**（参考）:

- 1アストラ = 10ムーン = 100グリム
- 1アストラ ≒ 1.2ドワーフクラウン = 0.8オークトーメン

## 主要産業

### 1. 魔導技術産業

**中心地域**: ゼフィア連合共和国、鉄山脉ドワーフ王国

- 魔導機械の製造
- 日常用品の魔導化（炊事、洗濯、照明など）
- 通信機器（精霊通信装置）
- 輸送機器（魔導馬車、飛空艇）

### 2. 神秘作物・薬草栽培

**中心地域**: 翡翠王国、リュミエラ（東大陸）

- エメラルドリーフ（神秘作物）
- 月草（月魔法補助薬草）
- 回復薬草
- 魔法ポーション原料

### 3. 鉱業・冶金

**中心地域**: 鉄山脉ドワーフ王国、カオス・リア（南大陸）

- 魔導金属（魔力伝導性の高い金属）
- 希少鉱物（クリスタル、オーパルなど）
- 普通金属（鉄、銅、錫）
- 宝石・貴金属

### 4. 観光業

**中心地域**: 月影エルフ王国、アトランティス女王領、自由都市連合

- 神秘遺跡巡礼
- 魔法体験ツアー
- 海底都市観光（アトランティス）
- 空中都市遺跡探検

### 5. 運輸・物流

**中心地域**: ゼフィア連合共和国、自由都市連合、ハーフリング商工業連合

- 陸路街道運輸
- 海上航路
- 空路（飛空艇）
- 公共交通機関

### 6. 魔法サービス

- 魔法学校の学费
- 契約精霊仲介
- 魔導装置メンテナンス
- 魔法防具・装備販売

| 大陸 | 主要輸出品 | 主要輸入品 |
|------|------------|------------|
| **エリュシオン（中央）** | 魔導機械、金融サービス、加工食品 | 原材料、神秘作物、鉱物 |
| **リュミエラ（東）** | 神秘作物、月魔法関連商品、芸術品 | 工業製品、鉱物、食料 |
| **カオス・リア（南）** | 鉱物、戦士派遣、遊牧製品 | 工業製品、食料、神秘作物 |
| **アトランティス（西）** | 海洋資源、潜水技術、水産物 | 工業製品、神秘作物、鉱物 |
| **グリモワール（北）** | 時空技術（限定的）、研究サービス | 全般的に輸入（自給力低） |

## 貿易の主要路線

### 陸上街道

- **中央街道**: ゼフィア～各主要都市を結ぶ大動脈
- **東街道**: エリュシオン～リュミエラ
- **南街道**: エリュシオン～カオス・リア
- **北街道**: エリュシオン～グリモワール（時空番人所管）

### 海上航路

- **中央海航路**: 中央大陸周辺の島々と往来
- **東海岸航路**: リュミエラ沿岸航路
- **南西航路**: アトランティス～自由都市連合
- **外海航路**: 危険だが、高価格品の密輸ルート

### 空路

- **飛空艇航路**: 主要都市間を結ぶ定期便（安全）
- **竜騎兵航路**: 軍事・緊急輸送
- **未開地空路**: 探検・調査用

## 労働市場

### 種族別雇用動向

| 種族 | 主要職種 | 平均年収（アストラ） |
|------|----------|---------------------|
| 人間 | 技術職、商人、官僚 | 50-100 |
| エルフ | 神秘学専門家、芸術家、学者 | 80-200 |
| ドワーフ | 技術者、鍛冶師、鉱夫 | 60-120 |
| オーク | 戦士、警備、建設労働 | 40-80 |
| ハーフリング | 商人、農夫、調理師 | 30-70 |

### 失業率（全体平均）

- **平均**: 約5%
- **地域差**: 発展地域（1-3%）、辺境地域（10-15%）

## 経済格差

### 地域間格差

- **富裕地域**: エリュシオン（中央大陸） - 一人当たりGDP最高
- **中地域**: リュミエラ、アトランティス - 特定産業で発展
- **開発地域**: グリモワール - 特殊機関のため経済規模小
- **発展途上地域**: 南大陸（カオス・リア） - 資源はあるが産業基盤弱

### 種族間格差

- 長寿種族（エルフ、ドワーフ）は蓄積資産が多い
- 短命種族（人間、オーク）は現金収入重視
- ハーフリングは商業で成功しやすい

## 税制

### 主要税種

1. **取引税**: 売買の2-5%
2. **所得税**: 収入に応じた累進課税（0-20%）
3. **関税**: 国際取引に適用（国ごとに異なる、通常5-10%）
4. **魔法利用税**: 魔法関連商取引に3%

### 税収使途

- 公共インフラ（街道、港、空港）
- 魔法学校運営
- 国際機関拠出金
- 安全保障（国軍、都市防衛）

## 経済政策

### 十二国同盟経済政策

- **自由貿易の促進**: 関税の段階的削減
- **共同通貨の検討**: 将来的なアストラ統合の議論
- **資源配分調整**: 不足地域への支援
- **技術共有**: 魔導技術の普及推進

### 各国独自政策

- **ゼフィア**: 技術革新支援、スタートアップ優遇
- **月影エルフ王国**: 神秘作物輸出統制、文化財産保護
- **ドワーフ王国**: 鉱業国家管理、技術輸出促進
- **ハーフリング連合**: 商業自由化、小規模事業者支援

## 経済団体・ギルド

### 主な経済組織

1. **十二国商工会議所**: 国際ビジネス協調
2. **魔導技術者ギルド**: 技術者认证・労働組合
3. **運輸組合**: 街道・航路・空路の物流協調
4. **神秘作物農家組合**: 翡翠王国中心
5. **冒険者ギルド**: 個人事業主のネットワーク

## 経済予測・課題

### 短期的課題（1-3年）

- 新型魔法技術による産業構造変化
- 若年労働力不足（短命種族の早期引退問題）
- 辺境地域の経済格差是正

### 中期的課題（5-10年）

- 環境負荷と持続可能性
- 老齢化（長寿種族の労働力高齢化）
- 技術革新による雇用構造変化

### 長期的課題（10年以上）

- 資源枯渇と代替資源開発
- 異世界・宇宙への経済圏拡大の可能性
- 魔法技術の国際管理と経済自由のバランス
