# 種族

エターナル・アルカディアに住む主要種族を紹介します。

## 主要種族一覧

### 1. 人間（Human）

| 項目 | 内容 |
|------|------|
| **平均寿命** | 80年 |
| **精霊契約率** | 30%（風精霊） |
| **特徴** | 適応力が高い、繁殖力が高い、短命だが成長が速い |
| **人口比** | 約45% |
| **主要国家** | ゼフィア連合共和国、自由都市連合、ハーフリング商工業連合 |

**概要**:
人間は最も多くの人口を持つ種族。精霊契約率は低いが、技術と組織力で世界をリードしている。短期間で高度な文明を築き、多種族社会の基盤を作った。

---

### 2. エルフ（Elf）

| 項目 | 内容 |
|------|------|
| **平均寿命** | 1500年 |
| **精霊契約率** | 80%（月精霊） |
| **特徴** | 長寿、魔法に優れる、芸術的センスが高い |
| **人口比** | 約15% |
| **主要国家** | 月影エルフ王国、林間地エルフ自治領 |

**概要**:
最初に精霊と契約した種族。月魔法の使い手として古い知識を保持。長寿のため思考が長期的で、他の種族とは時間感覚が異なることが多い。

---

### 3. ドワーフ（Dwarf）

| 項目 | 内容 |
|------|------|
| **平均寿命** | 300年 |
| **精霊契約率** | 75%（地精霊） |
| **特徴** | 技術力、地下居住、鉱業・冶金に優れる |
| **人口比** | 約12% |
| **主要国家** | 鉄山脉ドワーフ王国 |

**概要**:
地精霊との契約により、岩石と鉱物の操りを得意とする。技術大国。堅実で約束を重んじる文化。地下都市「ストーンヘイム」は世界七不思議の一つ。

---

### 4. オーク（Orc）

| 項目 | 内容 |
|------|------|
| **平均寿命** | 60年 |
| **精霊契約率** | 50%（火精霊） |
| **特徴** | 戦闘力、名誉重視、遊牧・狩猟文化 |
| **人口比** | 約10% |
| **主要国家** | 赤砂オーク連合 |

**概要**:
炎精霊との契約により、戦闘と狩猟に長ける。 Honor（名誉）と力の文化。遊牧生活を送る部族社会。近年は国家を形成し、外交力を高めている。

---

### 5. ハーフリング（Halfling）

| 項目 | 内容 |
|------|------|
| **平均寿命** | 120年 |
| **精霊契約率** | 40%（地精霊） |
| **特徴** | 幸運、商業・農業に優れる、小柄 |
| **人口比** | 約8% |
| **主要国家** | ハーフリング商工業連合 |

**概要**:
地精霊との契約により、農耕と商売の才に溢れる。幸運の種族として知られ、-border trade の中心。美食家で平和的。小柄だが知略に長ける。

---

### 6. その他の種族（Minor Races）

#### トンベリ（Tombli）

- 平均寿命: 50年
- 特徴: 夜行性、洞穴居住、採掘技術
- 人口: 少ないが分散

#### グノーム（Gnome）

- 平均寿命: 200年
- 特徴: 発明家、機械技術、精霊機械工房
- 人口: 少数

#### 妖精（Fairy）

- 平均寿命: 不詳（ immortal 種族）
- 特徴: 小型、自然精霊と親和、魔法の素養极高
- 人口: 極めて稀少

## 精霊契約システム

すべての種族は、**五元素精霊**のいずれかと契約を行い、魔法能力を得る。

### 五元素精霊

| 精霊 | 属性 | 特徴 | 主な契約種族 |
|------|------|------|--------------|
| **風精霊シルフィード** | 風 | 敏捷、通信、自由 | 人間（30%）、一部エルフ |
| **地精霊ノーム** | 地 | 堅牢、鉱業、農業 | ドワーフ（75%）、ハーフリング（40%） |
| **火精霊イグニス** | 火 | 攻撃、情熱、破壊 | オーク（50%）、一部人間 |
| **水精霊アクア** | 水 | 癒し、流動、海洋 | アトランティス諸都市、一部人間 |
| **月精霊ルナ** | 月 | 神秘、時間、予言 | エルフ（80%）、一部グリモワール住民 |

**契約の種類**:

- **完全契約**: 強力な力、厳格な制約
- **部分契約**: 制限された力、柔軟な使用
- **血統契約**: 種族全体への遺伝的契約
- **個人契約**: 個別の契約交渉による

## 種族間関係

### 歴史的背景

- **精霊契約期**: 種族間の大戦争（契約戦争）
- **近代契約期**: 人間を媒介とした融和
- **現代**: 十二国同盟による共存

### 現在の関係性

| 種族ペア | 関係性 | 備考 |
|----------|--------|------|
| 人間-エルフ | 友好 | 交易・文化交流活発 |
| 人間-ドワーフ | 友好 | 技術・資源取引 |
| 人間-オーク | 改善中 | 過去の戦争の記憶あり |
| エルフ-ドワーフ | 中立 | 価値観の違いあり |
| オーク-エルフ | 懸念あり | 文化的差異 |
| ハーフリング-全種族 | 友好 | 商売仲間として |

## 文化的特徴

### 価値観の違い

| 種族 | 重視する価値 | 時間感覚 |
|------|--------------|----------|
| 人間 | 実利、成長、革新 | 短期（50-100年） |
| エルフ | 伝統、美、永続 | 超長期（500-1000年） |
| ドワーフ | 職人技、約束、堅実 | 中期（100-300年） |
| オーク | 名誉、力、信義 | 短期～中期（60-100年） |
| ハーフリング | 幸運、美食、家族 | 中期（100-150年） |

## 混血種族

- **ハーフエルフ**: 人間×エルフ。長寿だが人間より短め、両方の文化を継承
- **ハーフドワーフ**: 人間×ドワーフ。技術と適応力の融合
- **クォーター種族**: 4種族以上の混血。稀だが多様な能力
