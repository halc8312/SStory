地図ギャラリー

ここでは生成済みの世界地図・大陸地図・地域地図・交通図をカテゴリ別に閲覧できます。

静的画像ギャラリーに加えて、Map Data と連携したインタラクティブマップ v1 / v2 への導線もこのページで整理しています。交通図の元データは world/map-data/ に整理されています。

インタラクティブマップの使い分け

  • interactive-map.html — 現行安定版。交通ノード、POI、ルート検索、旧SVGデバッグ表示、既存の公開APIを含みます。
  • interactive-map-v2.html — Beta / Experimental。フルスクリーン地図、Google Maps風UI、レイヤーパネル、ミニマップなど次世代候補のUIを正式評価中です。
