GitHub Pages 設定手順

このサイトを GitHub Pages で公開するには、以下の手順で設定します：

  1. GitHub のリポジトリページを開く
  2. Settings タブをクリック
  3. サイドメニューから Pages を選択
  4. Build and deployment を Deploy from a branch に変更
  5. Branch を main に選択
  6. Folder を /docs に選択
  7. Save ボタンをクリック
  8. 数分待つと、https://halc8312.github.io/SStory/ でサイトが公開されます

※ この設定は GitHub リポジトリの管理画面で行う必要があります。
PR ではファイルの追加のみを行い、Pages 設定自体は管理者が行ってください。
