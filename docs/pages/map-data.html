Map Data

Map Data とは

Map Data は、エターナル・アルカディア世界の地図情報を機械可読な形式で管理するための データセットです。JSON および GeoJSON 形式で、ノード（地点）、ルート（経路）、 危険区域、大陸・地域情報などを定義します。

これらのデータは、Python ツールで生成・管理され、将来的には Web ブラウザ上で JavaScript が読み込んでインタラクティブな地図表示に利用されます。

地図ギャラリーで生成済み地図を閲覧 →

データファイル一覧

world/map-data/ には以下のファイルを配置予定です：

  • nodes.json - すべての地点（都市、村、港、転送ゲートなど）の座標・属性データ
  • routes.json - 地点間を結ぶ経路（陸路・海路・空路）の接続情報と距離・所要時間
  • hazards.json - 危険区域（海獣出没地帯、異常気象域、魔物棲息地など）のポリゴン
  • continents.json - 五大陸の境界ポリゴンと基本情報
  • regions.json - 地域・国・州などの行政区画データ

将来のスポット追加に向けた設計方針は POI / Spot Design Guidelines に整理しています。

POI / スポットデータ

POI（Point of Interest）データは、都市施設・商店・宿屋・市場・神殿・ギルド・ 観光名所・ダンジョン入口など、地図上の特定スポットを管理します。

現在、POIデータ仕様 v0.1 に基づき、アストラリス首都圏と ポートゼフィア港湾圏への試験投入（22件）を実施しています。 中核POIは status: "active"、補助・拡張候補POIは status: "draft" とし、ID は astralis_ / port_zephia_ 接頭辞命名規則に従っています。 引き続き仕様・Schema・地図表示の整合確認を継続中です。

  • データファイル: world/map-data/data/pois.json （正史データ）
  • 公開用コピー: docs/data/map/pois.json （GitHub Pages用）
  • JSON Schema: world/map-data/schemas/poi.schema.json
  • 仕様書: world/map-data/docs/poi-data-spec.md

POIの追加・編集は、必ず POI設計ガイドライン と POIデータ仕様 v0.1 に従ってください。 特に lore_basis（世界観根拠）と historical_reason（歴史的理由）などの 必須根拠フィールドを充実させる必要があります。

※ 現段階では、アストラリス首都圏とポートゼフィア港湾圏への試験投入（22件）が完了しており、 JSON Schema 検証と公開用コピー同期を実施済みです。 Leaflet地図は docs/data/map/pois.json を読み込んでPOIレイヤーを表示します。

GeoJSON 出力

上記 JSON データは、GeoJSON 形式にも変換可能です。 GeoJSON は GIS ソフトや Leaflet、OpenLayers などの地図ライブラリで 直接読み込むことができます。

変換スクリプトは tools/map/ 配下にて提供予定です。

ルート検索ツール

現在、tools/map/route_finder.py というPythonスクリプトにより、 nodes.json と routes.json を読み込んで、2地点間の最短経路（Dijkstra法）を 計算できます。

ただし、これはローカルまたはCI環境で実行されるバックエンド用ツールです。
GitHub Pages 上では直接実行できません。
将来的には、このロジックを JavaScript に移植し、Web版ルート検索を実装予定です。

  • 出発地・目的地選択UI
  • 交通手段フィルタ（陸路/海路/空路）
  • 季節運行判定
  • 所要時間・距離の表示

Webマップ・タイルマップへの発展

Map Data は、以下の段階を経て Web 地図として展開される予定です：

  1. Map Data を Leaflet で表示（インタラクティブマップ v0.1）
  2. 生成済み地図画像をオーバーレイ
  3. タイルマップ化（小タイルに分割して効率的表示）
  4. 特定地域（アストラリス首都圏、紅海砂漠隊商路など）から試作

詳しくは ロードマップページをご覧ください。

GitHub Pages 公開用コピー

GitHub Pages 上でブラウザが直接 JSON を読み込めるように、 world/map-data/data/ の正史データを docs/data/map/ にコピーしています。

  • 正史データ本体: world/map-data/data/ （Python ツールや設定管理用）
  • 公開用コピー: docs/data/map/ （GitHub Pages 上から Fetch 可能）

更新時は world/map-data/data/ から手動で同期してください。 将来的には GitHub Actions による自動同期を検討中です。

インタラクティブ交通マップ（準備版）

インタラクティブ交通マップ準備ページ では、 docs/data/map/ の JSON をブラウザの JavaScript で読み込み、 ノード・ルート・危険区域の件数を表示しています。

v0.1 ではデータの読み込み確認と簡易一覧表示のみです。 次のフェーズで実際の地図描画（ノードを点、ルートを線、危険区域を領域で表示）を実装予定です。

Map Data 資料への導線

Map Data 関連の設定資料は以下の場所にあります：

  • world/map-data/ フォルダ - Map Data 仕様・データ定義
  • POI / Spot Design Guidelines - POI追加時の世界観整合ルール
  • tools/map/ フォルダ - ルート検索ツール・データ生成スクリプト

※ 現時点では、GitHub Pages 上で JSON ファイルを直接ブラウザ表示することはできません。
データは JavaScript から AJAX/Fetch で読み込む形になります。
