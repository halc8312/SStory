SStory / エターナル・アルカディアへようこそ

エターナル・アルカディアは、浮島と大海原が広がるファンタジー世界です。 このサイトは、その世界設定を体系的に整理・公開するためのポータルです。

現在は v0.1 の静的ポータルとして、世界設定の概要と各資料への導線を提供しています。 現在は、インタラクティブなWebマップ、POI検索、条件付きルート検索も利用できます。

地図ギャラリー

生成済みの世界地図・大陸地図・地域地図・交通図を、カテゴリ別に閲覧できます。
