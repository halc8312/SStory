## 7. JS/CSS分離の検討

### 現状
- v2は単体HTML（約2200行）にHTML/CSS/JSを全て含む
- v1はHTML(313行) + 外部CSS(`style.css`) + 外部JS(`leaflet-transport-map.js`, `interactive-map.js`)

### 分離候補
```
docs/pages/interactive-map-v2.html
docs/assets/css/interactive-map-v2.css
docs/assets/js/interactive-map-v2.js
```

### 検討結果
- 現時点では単体HTMLのまま維持が妥当
  - 試験版のため頻繁に変更が発生する
  - 単体ファイルの方がデバッグ・比較が容易
  - v1とのコード共通化は現時点では不要
- 主表示化決定後に分離を検討する
- GitHub Pages での読み込みは単体でも分離でも問題なし

---

## 8. 既知の問題

1. **ノードのピクセル座標が概算** — `pixel-mapping.json` は目視推定値。一部ノードの位置がずれている可能性
2. **POIの位置が粗い** — 31件のPOI全てがアストラリス周辺のみ。親ノードからのオフセットで配置
3. **深度ズームの地域マップ境界が概算** — 地域マップ画像の配置範囲は手動調整。一部重なりや隙間あり
4. **地域マップの装飾的枠線** — 既存の地域マップ画像には装飾枠があり、重ね合わせ時にやや不自然
5. **他4大陸の大陸マップが未生成** — エリュシオンのみ実装済み
