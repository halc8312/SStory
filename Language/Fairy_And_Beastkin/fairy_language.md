# 妖精語（Fairy Language / Faerie Tongue） - エターナル・アルカディア

**別名**: 光韻語、精華語、小花言葉、羽の言語
**話者**: 妖精族全員（推定 **75,000人** ±25,000） + 一部自然主義エルフ・ハーフリング（約3,000人）
**使用地域**: Lumiera大陸 翡翠ベルト森林全域、浮遊島、花園遺跡
**文字数**: 52文字（1年52週に準拠）
**文書形式**: 光跡・花弁・蜘蛛の糸・光結晶・羽根絵画

---

## 1. 歴史的概要

### 1.1 起源

妖精語は**光精霊・自然精霊との直接交信から生まれた言語**で、世界創造時に妖精種族が精霊より授かった。人类（種族）が最初に孤立させた言語の一つ。**-10000年（世界創造時）に起源を持ち、-5000年にLunaria帝国の影響を受け、森の妖精達が自然の中で体系化した**とされる。

**起源の特徴**:

- **精霊語の直接子孫**（Lunaria語が月精霊経由、妖精語は光/自然精霊直接）
- 音声が**超音波域**まで含む（人間には聞こえない部分あり）
- 書き言葉は**光・色・動き**で表現（静止画では不完全）
- 時間経過により変化する**「生きている言語」**

### 1.2 発達

**-10000年 ～ -5000年**: 妖精族内で孤立発達（古代精霊語を基盤に独自化）。
**-5000年 ～ -1000年**: Lunaria帝国との交流で、**52文字の光文字**が確立・記録化。
**-1000年 ～ 0年**: Zephyr古代王国の多種族外交で、一部が外部に流出。
**0年 ～ 現在**: 現代妖精語は50%が固有語、30%がエルフ語借用、20%が共通語借用。若い妖精は共通語も話すが、**長老級は妖精語のみ**。

### 1.3 現在の状況

- **完全話者**: 妖精全員（ほぼ100%）
- **部分話者**: 自然魔法師（エルフの10%が学習）、花農家（ハーフリングの5%）
- **学習者**: 月エルフ王国・自然魔法学校に年30名
- **保存状況**: **良好**（妖精族は口伝中心、書き言葉少ないが、光結晶記録が完全）

## 2. 言語学的特徴

### 2.1 音韻体系

**音素数**: 42音（人間可聴域32音 + 超音波10音）

**母音 (12)**:

```
a, e, i, o, u (基本)
ā, ē, ī, ō, ū (長音)
á, é, í, ó, ú (高音・強調)
```

**子音 (30)**:

```
P, B, T, D, K, G (無声・有声)
S, Z, Š (sh), Ž (zh), Ŝ (whisper), Ẑ (chirp)
M, N, Ŋ (ng), ŋ̍ (buzz)
L, Ł (soft l), R, Ř (trill), Ṙ (vibrato)
F, V, Ф (breathy), H, Ḥ (whistle)
C (ts), J (y), W, Y, Ꝏ (double u)
```

**特徴的発音**:

1. **高周波数**: 基本周波数2-8kHz（人間の上限8kHz、妖精は12kHzまで）
2. **超音波成分**: 10-20kHzの超音波を30%含む（妖精同士の秘密通信）
3. **歌的メロディ**: 1文が必ず音階パターン（上昇・下降・波形）を持つ
4. **共鳴**: 口頭だけでなく、**羽根の振動**・**光の闪烁**でも補完

### 2.2 文法構造

**基本語順**: VSO（動詞・主語・目的語）← Lunaria語の影響（精霊語系）

**名詞**:

- **6格**: 主格・属格・対格・与格・呼格・**光格**（光の強度による）
- **性**: 2性（陽：光/活性、陰：影/静寂）＋ **中性**（物質）
- **数**: 単数・双数・複数（双数は「対の花・双子妖精・光と影」）
- **人称**: 1/2/3人称 × 単数/双数/複数

**動詞**:

- **8時制**: 現在・過去・未来・完了・**花時**（開花時期）・**光時**（日照時間）・**羽時**（飛行時間）・**夢時**（夜間）
- **4様式**: 指示・命令・願望・**自然調和**（自然と同調）
- **態**: 能動・受動・中動・**羽移動**（飛行）・**光変化**（発光）

**特徴的構文**:

1. **光強度修飾**: 動詞に光強度（弱・中・強）の接頭辞
   - `(弱) lum-`（微光）, `(中) lumi-`（光）, `(強) luma-`（強光）
2. **羽位置語**: 飛行方向を語彙に組み込む
   - `tabi-`（上昇）, `sota-`（下降）, `kuri-`（旋回）
3. **自然時制**: 「春の朝」「夏の正午」「秋の夕」「冬の夜」で時制表現

### 2.3 語彙特性

**核心語彙領域**:

1. **自然・植物** (200語): 花・草・樹木・季節・天気
2. **光・色** (150語): 光度・色相・輝き・虹
3. **羽・飛行** (100語): 羽種類・飛行方法・速度
4. **治癒・魔法** (120語): 光魔法・回復・癒し
5. **感情・芸術** (80語): 喜び・優しさ・歌・踊り

**語形成**:

- **複合語主流**: 例 `lum-flori-kin`（光-花-翼）= 光る花の翼
- **接辞**: 接頭辞8種、接尾辞6種
- **繰り返し**: 同じ音を重ねて強調（例: `piki-piki`「チクチク」→ `pikipiki`「光チクチク」）

**借用語**:

- エルフ語から15%（特に神秘・魔法語）
- 共通語から10%（日常語）
- Grandoria語から2%（鉱物・技術語、妖精は技術に関心薄いため）

## 3. 文字体系：光韻文字（Lumina Verse）

### 3.1 基本設計思想

- **52文字** = 1年の52週（各文字が1週間に対応）
- 文字形状は**花弁・羽根・光輪・水滴**の4系統
- 文字は**静止画では不完全**、光・色・動きが3要素
- 書く時は**光を当てて撮影**、または**生きた植物に刻む**

### 3.2 文字一覧（4系統 各13文字）

#### A系: 花弁系 (Floral) - 13文字

```
基本形: 花弁5-8枚の radial 模様
文字例:
① 光 (lumina)    : 花弁+中心光点
② 花 (flori)     : 花弁のみ
③ 羽 (alata)     : 羽根形状
④ 水 (aqua)      : 水滴形状
⑤ 風 (aura)      : 風形花弁
...
```

#### B系: 羽根系 (Feather) - 13文字

```
基本形: 羽根の形状（3-7枚）
特徴: 羽軸・羽弁の細密表現
```

#### C系: 光輪系 (Halo) - 13文字

```
基本形: 円環・放射状光線
特徴: 光の強度を段階表現（内側の密度で）
```

#### D系: 水滴系 (Droplet) - 13文字

```
基本形: 水滴・雫形状
特徴: 落下方向で意味変化
```

### 3.3 書法规则（特殊）

1. **媒体依存**: 媒体により形状が微変化
   - 花弁に刻む: 花弁形状が反映
   - 光結晶: 光の折射パターン
   - 蜘蛛の糸: 糸の絡み方
2. **色必須**: 各文字に**必須色**あり（例: 光=黄色、花=桃色、羽=空色、水=青色）
3. **動的要素**: 静止画では read不可、**光の当て方**・**視点移動**で判別
4. **読み方**: 文字を**上から下**、**内から外**、**光の強い方から弱い方**へ

### 3.4 数字・日付

- **数字**: 1-52の各文字をそのまま使用（52週対応）
  - 1: 花弁系1（最小・ weakest）
  - 52: 光輪系13（最大・最強）
- **日付**: 年+週+曜日（妖精は7曜日ではなく52週暦）
- **曜日**: なし（52週制のため）

## 4. 文化的・魔法的意義

### 4.1 魔法における地位

- **光魔法・自然魔法の必須言語**: 妖精魔法は全て妖精語で発動
- **治癒魔法**: 最も効果的な言語（治癒力+30%）
- **植物会話**: 植物と会話する際の共通語（植物も理解）
- **羽魔法**: 飛行・風魔法の補助（妖精独自の飛行術）

### 4.2 社会文化における役割

- **妖精族のアイデンティティ**: 言葉を失うと「妖精でなくなる」（種族的絆）
- **歌と踊り**: 全てが言語と一体化（歌詞・振り付けに意味）
- **結婚儀礼**: 花弁に互いの名を刻み、光合成で保存（永遠の証）
- **年齢表現**: 「52週×年数」で年齢（例: 100歳=5,200週）

### 4.3 社会階層と言語アクセス

- **長老（500歳以上）**: 完全妖精語＋古語（52文字全使用可能、100名程度）
- **成人（100歳以上）**: 完全妖精語（95%語彙、20,000語）
- **若妖精（20-100歳）**: 85%語彙（日常・魔法基本）
- **子供（20歳未満）**: 60%語彙（単語・簡単な文）
- **他種族**: 学習可能だが超音波域が困難→30%までしか理解不可

### 4.4 禁忌

- **52文字一斉発声**: 光の爆発（過去1例、妖精村里消滅）
- **特定花弁文字の逆使用**: 花の逆成長（枯れ→咲く）が可能、 Nature order破壊
- **羽根文字の不正使用**: 他人の羽根に刻むと、その羽根が腐る（呪い）
- **光輪文字の暗所使用**: 暗闇で発光し、位置暴露（危険）
