# 獣人共通語（Beastkin Pidgin / Beast Common） - エターナル・アルカディア

**別名**: 野の言葉、混声語、狩人の言葉、牙の言語
**話者**: 獣人族全般（全種族合計 **推定135,000人** ±15,000）
**使用地域**: Chaos-Rea砂漠周辺・荒野・森林全域、国境地域
**文字数**: 28文字（共通語アルファベットから派生）
**文書形式**: 木彫り・岩刻画・布・皮革・unjarred骨

---

## 1. 歴史的概要

### 1.1 起源と成立
獣人共通語は**複数の獣人族部族間の交易・交流から自然発生したピジン言語**である。正確な起源年代は不明（-2000年頃から）。

**成立の経緯**:
1. **-2000年頃**: Chaos-Rea砂漠周辺で、オーク・ハーフリング・獣人が交易開始
2. **-1500年頃**: 交易語として自然発生（各言語から単語を借用・簡略化）
3. **-1000年頃**: 文法が固定化、**28文字の簡易文字**が制定
4. **0年頃**: 十二国連合により**「獣人部族共通語」** として公式認定
5. **現在**: 獣人族の95%が理解、ただし流暢に話すのは40%

### 1.2 社会的背景
- **獣人族の多様性**: 猫系・犬系・鳥系・爬虫類系・鼬系など**30+種**が存在
- **言語の多様性**: 各部族に固有語あり（猫族語、狼語など）→ 意思疎通不可
- **必要性**: 交易・同盟・共同狩猟・部族会議に必須
- **性質**: **ピジン（pidgin）** → **クレオール（creole）** へ移行中（若者は母語化）

### 1.3 現在の状況
- **完全流暢話者**: 40%（主に商人・傭兵・部族長）
- **部分理解**: 55%（日常会話のみ）
- **非話者**: 5%（最奥部族・孤立部族）
- **学習**: 子供期に自然習得（学校教育なし）
- **保存**: 良好（口語中心、書き言葉少ないが、交易路で伝承）

## 2. 言語学的特徴

### 2.1 音韻体系

**音素数**: 24音（共通語25音から`Q`・`X`を除外）

**母音 (5)**: `a, e, i, o, u`（長短区別なし）
**子音 (19)**:
```
P, B, T, D, K, G
S, Z, Š (sh), Ž (zh)
M, N, Ŋ (ng)
L, R
F, V, H
C (ts), J (y), W, Y
```

**特徴的発音**:
1. **動物音模倣**: 語源が動物行動から（例: `grrr`「怒り」、`mew`「猫」）
2. **短母音**: 全母音短め（迅速発話）
3. **破裂音強調**: `k, g, t, d, p, b` を強く（野生動物の roar 模倣）
4. **子音の重ね**: 許容（`grr`, `rrr`, `sss` など擬音語）

### 2.2 文法構造（極めて単純）

**基本語順**: **SVO**（主語・動詞・目的語）← 共通語と同じ

**名詞**:
- **2格**: 主格・対格（属格・与格は前置詞で代用）
- **性**: 無性（全名詞中性）
- **数**: 単数・複数（複数は語尾に `-s` または `-es`）
- **人称**: 3人称のみ（1・2人称は代名詞で代用）

**動詞**:
- **2時制**: 現在・過去（未来は `will` で表現）
- **2様式**: 指示・命令（推論・願望は後述の副詞で）
- **活用**: ほぼなし（`-s`（3人称単数）のみ）
  - `I hunt`, `you hunt`, `he hunt-s`

**特徴的構文**:
1. **重文 common**: 短い文を連続（`I go. You stay.`）
2. **前置詞多用**: `in`, `on`, `at`, `for`, `with` で格を補う
3. **副詞で修飾**: 動詞の前に副詞（`fast hunt`、`strong hit`）

### 2.3 語彙特性

**核心語彙領域**（約1,500語）:
1. **生存・狩猟** (300語): 狩猟・採集・罠・追跡
2. **部族・社会** (200語): 部族名・階級・家族
3. **戦闘・防御** (250語): 武器・戦術・戦場
4. **自然・地形** (200語): 地形・気候・植物・動物
5. **感情・意思** (150語): 怒り・喜び・欲求
6. **交易・物資** (200語): 物々交換・商品・価値
7. **身体・行動** (200語): 身体部位・動作

**語形成**:
- **複合語少ない**: 単語は単独か、`noun + noun`（`rock-stone`）程度
- **接辞**: 接頭辞3種（`un-`（否定）、`super-`（超）、`mini-`（小））、接尾辞2種（`-er`（人）、`-ing`（行動中））
- **繰り返し**: 擬音語で多用（`grr-grr`「唸り」、`mew-mew`「鳴き」）

**借用語**（全語彙の70%）:
- 共通語: 40%（交易語として）
- オーク語: 15%（戦闘語）
- ハーフリング語: 10%（交易・農耕）
- エルフ語: 3%（神秘・魔法）
- ドワーフ語: 2%（鉱物・技術）
- 各獣人部族語: 30%（動物名・狩猟語）

## 3. 文字体系：部族刻印文字（Tribal Mark）

### 3.1 基本設計思想
- **28文字** = 共通語アルファベットの簡略版（`Q`, `X` を除外）
- 形状は**直線的・簡単**（岩刻画に適す）
- 読み書きできる者は10%未満（ほぼ口語言語）

### 3.2 文字一覧（共通語準拠）
```
A B C D E F G H I J K L M N O P R S T U V W Y Z
（Q, X 欠如）
```

**特徴**:
- 全て大文字（小文字なし）
- 文字は単純な線・点・三角（容易に彫刻可能）
- 読む方向: 左→右、上→下（共通語と同じ）

### 3.3 書法规则
1. **簡略化**: 複雑な曲線は直線化（例: `S` → `5` に近い）
2. **大きさ**: 文字高さ揃え（等幅）
3. **材料**: 石・木・皮・骨（紙は高級、一般には不存在）
4. **読み書き教育**: 部族長・商人のみ（10%）

### 3.4 数字表現
- **数字**: 共通語の数字語をそのまま使用（`one, two, three...`）
- 書く時: ローマ数字風（I, II, III, IV, V, X, L, C, D, M）
- 計算: 指計算・算珠（soroban 類似）が主流

## 4. 文化的・実用的意義

### 4.1 社会における地位
- **交易共通語**: 獣人族の経済活動の基盤
- **部族会議公用語**: 年1回の大集会（All-Beast Council）で使用
- **戦場通信**: 異部族混成部隊の指揮言語
- **結婚・契約**: 異部族間契約の公式言語

### 4.2 階層と言語アクセス
- **部族長・商人**: 完全流暢（読み書き可）
- **成人男子**: 日常会話可能（話せないと他部族と交易不可）
- **女性・子供**: 基本語彙のみ（150語）
- **老人**: 部族固有語のみ（獣人共通語不得意）

### 4.3 禁忌・規制
- **部族秘密語**: 各一部族に秘密語あり（獣人共通語では話さない）
- **精霊名**: 特定の精霊名は禁忌（部族の守護精霊）
- **成人儀礼**: 成人時に獣人共通語テスト（不合格者は部族長になれない）

## 6. 書き言葉と読み書き能力

### 6.1 文字使用状況
- **読み書きできる者**: 10-15%（主に部族長・商人・呪術師）
- **書き用途**:
  1. **部族の印**: 縄張り表示（木に刻印）
  2. **交易記録**: 物々交換の数量記録（骨・皮）
  3. **警告・伝言**: 危険情報の岩刻画
  4. **部族の歴史**: 重要な戦い・移動の記録（稀少）
- **読めない者は**: 口頭のみ、記憶依存

### 6.2 文字の変種
1. **刻印文字** (Mark Script): 岩・木に刻む（最も一般的）
2. **絵文字風** (Picto): 簡単な絵で表現（`鹿=🦌`, `家=⛺` の原型）
3. **数字記号**: 刻印の本数で数（I, II, III, IIII）

## 7. 他言語との関係

### 7.1 借用語比率
| 借用元言語 | 借用率 | 主な分野 |
|------------|--------|----------|
| 共通語 | 40% | 基礎語彙、数字、時間 |
| オーク語 | 15% | 戦闘、威嚇、身体 |
| ハーフリング語 | 10% | 交易、農作物 |
| エルフ語 | 3% | 自然、神秘 |
| ドワーフ語 | 2% | 鉱物、技術 |
| 各獣人固有語 | 30% | 動物名、狩猟行動 |

### 7.2 他言語からの影響度
- **文法**: 共通語のSVOを大枠で採用（理解容易）
- **発音**: オーク語の破裂音強め、エルフ語の母音を簡略化
- **語彙**: 実用的な1500語のみ（他の言語の5000+語に比べて小さい）

### 7.3 他の獣人部族語との比較
- **猫族語** (Feline Tongue): 柔らかい音、高音域、 secrecy
- **狼語** (Wolf Tongue): 低音、長距離通信、 pack 概念強
- **鳥語** (Avian Tongue): 高速、歌的、高度概念
- **爬虫類語** (Reptilian Tongue): 低周波、 Territorial
- **→ これらが混ざったのが獣人共通語**

## 8. 社会的機能と禁忌

### 8.1 言語の社会的役割
1. **異部族結婚**: 夫婦が異部族の場合、家庭では獣人共通語
2. **交易市場**: 国境都市（Free City States）で必須
3. **傭兵部隊**: 異部族混成部隊の指揮言語
4. **部族会議**: 年1回大集会（50部族以上が参加）
5. **.children教育**: 親は部族語、村全体では獣人共通語

### 8.2 禁忌と規律
- **部族秘密**: 各部族に秘密語あり（長老のみ知る）
- **狩猟儀礼語**: 特定の狩猟儀式では部族語のみ使用
- **精霊名**: 守護精霊の真名は獣人共通語で呼ばない（部族語のみ）
- **恋愛語**: 愛情表現は部族語のみ（共通語では軽率とされる）

## 9. 未来と変化

### 9.1 言語の変化
- **若年層**: 共通語の単語を積極的に借用（`phone`, `magic`, `city` 等）
- **年長層**: 伝統的獣人語を保持（部族語との境界あいまい化）
- **100年後予測**: 獣人共通語がさらに简化、共通語との差が縮小

### 9.2 標準語化の可能性
- **現在**: 標準なし（地域・部族で差あり）
- **将来**: Chaos-Rea中心部の方言が標準になる可能性
- **教育**: 十二年制学校で獣人共通語が必修化の動き（現在は口伝のみ）

### 9.3 消滅リスク
- **低**: 話者数15万人、若年層も学習
- **リスク要因**: 都市化（共通語に移行）・部族崩壊
- **保護活動**: 各部族が「言語継承者」を選出、口伝文学の保存
