# 言語開発ロードマップ - エターナル・アルカディア

**プロジェクト**: SStory Language Development
**バージョン**: 1.0.0 (2026-05-01 設計完了)
**ステータス**: Phase 1 (設計) 完了 → Phase 2 (詳細化) へ移行

---

## 📌 概要

エターナル・アルカディア世界の言語体系を、**6言語の基本設計**から**完全実装・公開**まで拡張するロードマップ。

**目標**:

- 全言語の語彙を500-1000語に拡充（現在~100語）
- 全文字のSVG/フォント実装（412文字）
- 音声データの作成（6言語分）
- 英語訳の作成（国際化）
- Webサイト公開（GitHub Pages）
- TRPGルール統合

**Month 1-2 合計**: ~75時間

#### Month 3-4: 方言定義 & 文字SVG作成 (2026-07 ～ 08)

**方言定義**:

- Lunaria: 月影・星霜・翡翠（既存）→ 各50語差を明記
- Grandoria: 山脈・都市・深淵（既存）→ 技術用語差を明記
- Zephyr: 標準語のみ（必要なら地域変種後述）
- 妖精: 光・影・風方言（新規定義、各30語差）
- 獣人: 猫族・狼族・鳥族方言（新規、各20語差）

**文字SVG作成**:

- 全412文字を vector 化（inkscape または手動）
- 各文字の規格化（幅・高さ・線幅統一）
- 月・地脈・風・光・刻印の5系統でカラー分類

**Month 3-4 合計**: ~100時間（SVG作成がボリューム）

#### Month 5-6: フォント作成 & 音声生成 (2026-09 ～ 10)

**フォント作成**:

- FontForge で TTF/OTF 生成（6言語分）
- 各フォントに合字（ligature）設定（Lunaria・妖精など）
- オープンソース公開用のライセンス確認（OFL推奨）

**音声生成**:

- 各言語100文をAI音声（ elevenlabs や OpenVoice）で生成
- 発音ガイド付き（IPA + 音声ファイルリンク）
- 音声アーカイブ（`.mp3` 1500ファイル予定）

**Month 5-6 合計**: ~80時間（音声生成が時間かかる）

### Phase 3: 統合 (6ヶ月計画)

#### Month 7-8: 本編統合 & 系統樹 (2026-11 ～ 12)

**主要タスク**:

1. `world/culture/languages.md` に6言語の概要を統合（現在の7言語に6言語追加で13言語）

- フォント・音声の埋め込み
- 検索機能（lunr.js）

**英語訳**:

- 全6言語の英語版作成（Google Translate + 手動校正）
- bilingual ページ（日本語/English 切り替え）
- 用語集の英語版

#### Month 11-12: テスト & 公開 (2027-03 ～ 04)

**内部テスト**:

- リンク切れチェック
- 発音記号の正確性確認
- 語彙の重複チェック
- 歴史的矛盾の最終確認

**プレビュー公開**:

- SStory本編に統合（PR作成）
- コミュニティフィードバック募集（1ヶ月）
- 必要に応じて修正

**正式公開**:

- 本編リポジトリにマージ
- website 公開（GitHub Pages）
- 告知（Twitter, Discord, 世界構築フォーラム）

### Phase 4: 拡張 (2027-2028)

#### 新言語の追加（候補）

1. **盗賊の隠語** (Thieves' Cant): 獣人語の派生、犯罪者専用

## 🛠️ ツール・リソース

### 制作ツール

- **設計・文書**: VS Code + Markdown
- **SVG作成**: Inkscape（無料）または Adobe Illustrator
- **フォント生成**: FontForge（無料）または Glyphs
- **音声生成**: elevenlabs API / OpenVoice（ローカルAI）
- **Webサイト**: Jekyll / plain HTML-CSS
- **バージョン管理**: Git + GitHub

### 参考資料

- **内部**: SStory world/ フォルダ全ファイル
- **外部**: 世界構築ガイド（Mark Rosenfelder）、言語作成本（The Art of Language Invention）
- **言語学**: 自然言語の音韻・文法リファレンス（英語・日本語・エスペラント）

### 予算（推定）

- **人的コスト**: 300時間（AI作業だが、人間のレビュー時間含む）
- **金銭的コスト**: ほぼ0円（全てOSS・無料ツール）
- **音声生成API**: ElevenLabs 有料プラン（$50/月、6ヶ月= $300）
- **Webホスティング**: GitHub Pages 無料

## ⚠️ リスクと対策

| リスク | 内容 | 発生確率 | 影響度 | 対策 |
|--------|------|----------|--------|------|
| 音声生成の品質低 | AI音声が不自然 | 中 | 中 | 複数AI比較、手動修正 |
| 語彙の重複・矛盾 | 全6言語で語彙整合性 | 高 | 高 | 語彙データベースで管理 |
| 歴史的矛盾の発見 | 後から世界観と矛盾 | 中 | 高 | 世界観文書と常に連携 |
| モチベーション低下 | 長期プロジェクト | 中 | 高 | マイルストーン達成で自己称賛 |
| 技術的難易度 | SVG/フォント作成初回 | 低 | 中 | チュートリアル学習から |
| 英語訳の遅延 | 日本語→英語の品質 | 高 | 中 | ネイティブ校正依頼（後述） |
