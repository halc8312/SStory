# Language フォルダ - エターナル・アルカディア言語体系

このフォルダには、エターナル・アルカディア世界の**6言語の完全設計**が収められています。

## カノン上の位置づけ

`Language/` は架空言語の設計・実験領域であり、内容は**提案段階（非カノン）**です。話者数、語彙、歴史、文法、ロードマップは、`world/` 配下のstableなカノン文書へ採用されるまで公式設定として扱いません。

採用済みの言語設定は [`world/culture/languages.md`](../world/culture/languages.md) を正とします。両者が矛盾する場合は同文書を優先し、新しい設定を採用する際はカノン文書へ反映してレビューしてください。詳細は [`CANON_POLICY.md`](../CANON_POLICY.md) を参照してください。

## 🗣️ 6言語の概要

### 1. Lunaria古代帝国語

- **文明**: 月魔法帝国（-5000年～-3000年）
- **文字**: 108文字（月の108夜 cycle）
- **特徴**: 神秘・予言・月魔法。12時制・8格の複雑な文法。
- **話者**: 47人（アールディー1026年、ほぼ絶滅）
- **復元率**: 35%

### 2. Grandoria古代王国語

- **文明**: 地技術王国（-3000年～-1000年）
- **文字**: 144文字（地脈12×12 grid）
- **特徴**: 技術・工学・地脈操作。16時制・12格。
- **話者**: 0人（学習者23名）
- **復元率**: 22%

### 3. Zephyr古代王国語

- **文明**: 外交国家（-1000年～0年）
- **文字**: 80文字（風の流れ）
- **特徴**: 外交・契約・多種族通信。4時制・4格の単純さ。
- **話者**: 0人（学習者45名）
- **復元率**: 28%
- **子孫**: 現代共通語（80%の基盤）

### 4. 妖精語 (Fairy Language)

- **種族**: 妖精族
- **文字**: 52文字（1年52週、花弁・羽根・光輪）
- **特徴**: 光・自然・治癒。超音波通信（10-20kHz）。歌的メロディ。
- **話者**: 75,000人（完全話者）
- **状態**: 現役言語（保存良好）

### 5. 獣人共通語 (Beastkin Pidgin)

- **種族**: 獣人族（30+部族）
- **文字**: 28文字（簡略化アルファベット）
- **特徴**: 交易・実用・単純（2時制・2格）。70%が借用語。
- **話者**: 135,000人（流暢40%）
- **状態**: 現役言語（ピジン→クレオール移行中）

### 6. 古代精霊語 (Ancient Spirit Script)

- **話者**: 精霊全般（100万+）
- **文字**: なし（自然現象そのもの）
- **特徴**: 非言語的5次元通信（時間滑走・エネルギー波・感情直結・現象談話・夢通信）。全文明の根源。
- **人間理解度**: 0.01%
- **状態**: 完全絶対言語（理解不可能）

## ❓ よくある質問

**Q: なぜ6言語も作ったのか？**
A: 三古代文明＋現代生言語2＋根源言語が必要だったため。歴史的深度と文化的多様性を表現するため。

**Q: 実際に話せるのか？**
A: 話者数0の古代語は学習可能だが20年必要。妖精語・獣人語は現役なので理論的には可能（学習期間5年・1年）。ただし、古代精霊語は人間には理解不能。

**Q: 音声はあるの？**
A: 現在はなし。2026年10月以降、AI音声を生成予定。

**Q: フォントは使える？**
A: 未作成。2026年12月以降、SVG + TTF/OTF を公開予定。

**Q: 他の言語を追加できる？**
A: 可能です！Issue/PR で提案してください。特に「秘密言語」「港町ピジン」「機械語」などを予定。

**Q: 英語訳は？**
A: 2027年中を目標に翻訳中。協力者募集中。

## 📖 学習ガイド（推奨）

### 初心者（初めての方）

1. まず `index.md` を読む
2. 各言語の「概要」部分だけを読む
3. 表比較を見る
4. 気になる言語の詳細へ

### 中級者（設定組み込み者）

1. 各言語の「代表的な単語・術式」を読む
2. 文化的位置づけを理解
3. キャラクターにどの言語を割り当てるか決める
4. 語彙リストから必要な単語を抽出

### 上級者（言語デザイン愛好家）

1. 音韻体系・文法を完全理解
2. 各言語の「歴史」を年表と照合
3. 文字SVGを実装（Scripts/ フォルダ）
4. 新たな方言・語彙を提案

## 🎓 用語集

| 用語 | 意味 |
|------|------|
| **古代語** | 三古代文明の絶滅言語（Lunaria, Grandoria, Zephyr） |
| **生言語** | 現在も話者がいる言語（妖精語、獣人語） |
| **根源言語** | 精霊が話す根源言語（古代精霊語） |
| **復元率** | 原文書の何％が解読済みか |
| **話者数** | 完全に話せる人の数 |
| **学習期間** | 人間が習得する推定年数 |
| **魔法効率** | その言語で詠唱したときの魔法成功率上昇率 |
| **精霊語** | 精霊たちのコミュニケーション（古代精霊語の現代表現） |
