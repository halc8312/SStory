# Grandoria古代王国語 - エターナル・アルカディア

**別名**: 岩窟古典語、地脈語、第二精霊語、石語（いしごと）
**時代**: 古代期（-3000年 ～ -1000年）
**使用文明**: Grandoria王国（地魔法・技術文明）
**現在の話者**: **0人**（完全絶滅語）、復元研究中。**学習者23名**（Ironridge Mining University 在籍、2026年現在）
**文字数**: 144文字（地脈12×12グリッドに基づく）
**文書形式**: 石盤・金属板・地脈結晶・建築彫刻

## 1. 歴史的概要

### 1.1 起源と成立
Grandoria古代王国語は**地精霊Granusの言葉を幾何学化・技術化**した言語である。紀元前3000年、三精霊契約時代中期に、**地脈の加護を受けた石工・技術者達**が、地脈の流れを図面化する過程で生まれた。

**成立の特徴**:
- **地脈エネルギー grid（12×12=144地点）** を各文字に対応
- 文字そのものが**微細な地脈回路**として機能（石に刻むと微弱な地魔法発動）
- 技術的精密性を反映した**完全な幾何学形状**
- **立体性**: 2次元のみならず3次元彫刻でも読める（地中深くの印にも対応）

### 1.2 繁栄と変遷
**-3000年 ～ -2000年**: 王国の国語・技術言語・学術言語の三役を果たす。
**-2000年 ～ -1200年**: 地脈技術の絶頂期。言語も高度化、**専門用語100万語**超と言われる。
**-1200年 ～ -1000年**: 地脈乱れによる社会混乱で、言語の standardization（標準化）崩壊。地方分権化で方言急増。
**-1000年**: **大流失事件**（Ley Line Catastrophe）により、中心部Grandoria都市圏ごと地中に沈み、**Master Lexicon「地脈法典」** の全複写本が消失。

### 1.3 現状と保存状況
現在、判読可能なのは以下のみ：
- **地脈法典 写本I**（Ironridge Dwarf Kingdom 地下博物館 所蔵） - 全文の5%
- **Grandoria技術書 断片**（世界各所の遺跡から出土、47点）
- **地魔法詠唱式**（Ironridge Mining University で継承中の60式）
- **建築銘板**（沈没都市Grandoria外壁に残る16枚）

復元プロジェクトはIronridge Dwarf Kingdom主导で進行中（2140年完了予定）。しかし、**文字の70%が未解読**、**専門用語の90%が謎**という絶望的状況。

## 2. 言語学的特徴

### 2.1 音韻体系（推定）

**音素数**: 40音（現代ドワーフ語28音 + 12古音）

**母音 (10)**:
```
ā (長母音・大地)   → アー
ē (鉱脉)          → エー
ī (水晶)          → イー
ō (溶岩)          → オー
ū (坑道)          → ウー
ǎ (地震)          → ア・鋭い
ě (地脈流)        → エ・揺れ
ǐ (振動)          → イ・高周波
ǎ̇ (空洞)         → ア・空洞音
ė (地鳴り)        → エ・重低音
```

**子音 (30)**:
```
P, B, T, D, K, G (無声音・有声音 対)
Q (kʷ), X (χ), H (ħ) （地鳴り音）
S, Z, Š (石裂き), Ž (地軋み) （摩擦音）
M, N, Ŋ (ng), ŋ̍ （共鳴・空洞音）
L, Ł (石擦れ), R, Ř (地脈振動) （液体/振動音）
F, V, Θ (th), Ð (dh) （風穴音）
C (ts), J (y), W, Y
```

**特徴的発音**:
- **母音の長さ**: 1拍・2拍・3拍で意味が変化（例: `kāra`「山」 vs `kara`「岩」）
- **子音の「地脈周波数」**: `ř`, `ž`, `š` などの摩擦音は地脈振動数を模倣（発音時、周囲の石が微振動）
- **母音の「空洞共鳴」**: `ǎ̇`, `ė` は口腔形状が地下空洞を模倣（発音時に顔面共振）

### 2.2 文法構造

**基本語順**: SOV（主語・目的語・動詞）← 現代ドワーフ語と同一（変化せず）

**名詞**:
- **12格**: 主格・属格・与格・対格・具格・経格・向格・呼格・**地格**（地脈上位置）・**層格**（地下深度）・**鉱格**（鉱石種類）・**時格**（地脈時制）
- **性**: 無性（全名詞中性）
- **数**: 単数・双数・複数
- **人称**: 3人称のみ（1・2人称は後代に追加）

**動詞**:
- **16時制**: 現在・過去・未来・完了・地脈現在（現時点の地脈状態）・地脈過去・地脈未来・**層時制**（深度別時間）・**鉱物時制**（岩石年代）・**凝固時制**（魔法固化時） etc.
- **5様式**: 指示・命令・願望・技術的推論・地脈解釈
- **態**: 能動・受動・中動・**地脈操作**（地形変化）・**鉱物変換**

**特徴的構文**:
1. **地脈指定構文**: 全ての文に地脈座標（X,Y）必須（例: `Kāra 12,7 bāra` = 「(12,7)地点に山が立つ」）
2. **層深度接頭辞**: 動詞の前に深度（1-1000m）を付与（例: `100 bāra` = 「100m深に立つ」）
3. **鉱物修飾語**: 名詞に鉱物名を後置（例: `kāra granite` = 「花崗岩の山」）

### 2.3 語彙特性

**核心語彙領域**:
1. **地脈技術** (300語超): 地脈流、エネルギー、共振、 etc.
2. **鉱物・金属** (500語超): 全既知鉱物のGrandoria名
3. **工学・建築** (400語超): 建設、構造、力学、 etc.
4. **時間・地層** (200語超): 地質年代、層序、年代測定
5. **魔法術式** (150語): 地魔法、地形変容、金属変換

**語形成**:
- **複合語90%**: 例 `gran-rock-fū`（地-石-風）= 「地脈石の風」（地脈エネルギー流れ）
- **接尾辞**: `-kā`（場所）, `-tī`（技術）, `-ra`（物）など30種
- **数字**: 12進法（地脈 grid 12×12に準拠）

**借用語**:
- 後代のドワーフ語へ2,000語以上 transfer（特に工学・鉱物語）
- 人間語へ300語程度（地脈・鉱物・工学概念）
- 精霊語から直接：ほぼなし（Granusとの直接契約が前提のため不要）

## 3. 文字体系：地脈幾何学文字（Geolith Script）

### 3.1 基本設計思想
- **144文字** = 地脈の12×12 grid（各文字が1 grid 座標に対応）
- 文字形状は**完全幾何学**（円・三角・四角・多角形の組み合わせ）
- 各文字が**特定の地脈座標**に相当（石板に刻むとその地点の地脈エネルギーを増幅）

### 3.2 文字分類（4系統 各36文字）

#### A系: 円系 (Circle-based) - 36文字
```
基本形: ○ ● ◯ ◎ ⚪ ⚫ ⦿ ⦾
組み合わせ: ○+点 ●+線 ◯+角 ◎+多角形 etc.
```
**使用例**: 水流・空洞・循環関連語

#### B系: 三角系 (Triangle-based) - 36文字
```
基本形: △ ▲ ▽ ▼ ▽ ▲
組み合わせ: △+点 ▲+線 ▽+角 etc.
```
**使用例**: 山岳・方向・力関連語

#### C系: 四角系 (Square-based) - 36文字
```
基本形: □ ■ ▢ ▣ ▤ ▥
組み合わせ: □+点 ■+線 ▢+角 etc.
```
**使用例**: 建築・区画・地盤関連語

#### D系: 多角系 (Polygon-based) - 36文字
```
基本形: 五角形・六角形・八角形など
組み合わせ: 多角形+内部模様
```
**使用例**: 複雑地脈・高度技術・神秘技術

### 3.3 書法规则
1. **方向**: 左→右、上→下（通常）だが、**地脈図**では radial（放射状）配置も可
2. **立体性**: 2D描画と3D彫刻の両方で読める（奥行き表現に段差利用）
3. **インク/彫刻**: 鉄錆 pigment（赤）・地脈結晶粉（青）・硫黄（黄）など材質で色分け
4. **読む条件**: 地脈 energy level が一定以上でないと発動しない（暗号化）

### 3.4 数字・座標表現
- **数字**: 12進法
  - 1-12: 基本記号（各系の1文字）
  - 13-144: 組み合わせ（X×12+Y で計算）
- **座標**: `(X,Y)` 表記（X=東西, Y=南北）
  - 例: `(7,3)` = 7番格子×3番格子
  - 12×12 grid で合計144地点
- **深度**: 数字の下に `_` + メートル数（例: `100m`）

## 4. 文化的・魔法的意義

### 4.1 魔法における地位
- **地魔法詠唱の必須言語**: 地魔法はGrandoria語で詠唱しないと効果0.5%以下
- **地脈操作**: この言語のみが地脈エネルギーを直接制御可能
- **技術魔法**: 工学的思考が必要な術式には必須（例: 都市防御壁構築）

### 4.2 技術的影響
- **現代ドワーフ語技術用語の70%**: Grandoria語から transfer
  - 例: `gran-rock`（地脈石）, `fū-line`（エネルギー流路）, `kāra-sys`（山脈システム）
- **地脈理論**: 現代の地脈研究はGrandoria語の論文を解読することが基礎
- **鉱物学**: 全鉱物のGrandoria名が国際標準（例: `Odin Steel` = `ōdīn-steel`）

### 4.3 社会階層と言語アクセス
- **Grandoria Master Engineer**: 144文字全文字と全地脈座標を暗記（10人程度）
- **地魔法師**: 50-100文字と術式語のみ
- **一般ドワーフ**: 20-30文字（生活必需語のみ）
- **他種族**: 実質0（地脈感覚なしでは学習不可能）

### 4.4 禁忌と危険性
- **全144文字一斉刻印**: 地脈暴走（過去1例、都市沈没の直接原因）
- **深度0m（地表）で地格使用**: 大地が反発し地震発生
- **特定鉱物語と地脈座標の組み合わせ**: 意図しない鉱脈形成（危険）
- **地脈時制の誤用**: 時間の地層が乱れ、過去の地層が噴出

## 7. 技術的・歴史的重要性

### 7.1 三文明との比較
Grandoria語は**最も技術的・実用的**な古代言語。Lunaria語（神秘）とZephyr語（社交）の対極。

**比較表**:
| 項目 | Lunaria | Grandoria | Zephyr |
