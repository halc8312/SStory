# Zephyr古代王国語 - エターナル・アルカディア

**別名**: 風紋古典語、外交古語、第三精霊語、契約の言葉
**時代**: 古代期末期（-1000年 ～ 0年）
**使用文明**: Zephyr古代王国（人間中心の多民族国家）
**現在の話者**: **0人**（完全絶滅語）、わずかに復元。**学習者45名**（精霊協会30名＋外交官15名、アールディー1026年現在）
**文字数**: 80文字（風の流れ・8方向×10段階）
**文書形式**: 羊皮紙・布・木簡・風鈴板

---

## 1. 歴史的概要

### 1.1 起源と成立

Zephyr古代王国語は**風精霊Zephyrosのコミュニケーション概念を実用化**した言語である。紀元前1000年、三精霊契約時代末期に、**人間族長達が精霊との契約を効率化するため**に開発された。

**成立の特徴**:

- **精霊契約の効率化**が目的（従来の精霊語は非効率）
- **多種族間共通語**として設計（人間・エルフ・ドワーフ・オーク・ハーフリングの5種族が話者）
- 文字は**風の流れを模した曲線**（書写・運搬の容易さを重視）
- 音声は**明瞭で発音しやすく**、各種族の音声特徴を調整

### 1.2 繁栄と変遷

**-1000年 ～ -500年**: Zephyr古代王国の国語・外交語・契約語として機能。**精霊協会の設立**（-800年）により、国際公用語化。
**-500年 ～ 0年**: 交易が盛んになり、各国で簡略化が進む。現代共通語の原型が形成。
**0年**: Zephyr古代王国が十二国連合に移行、Zephyr古代王国語を**公式語**として現代共通語を制定。以来、古代語は儀礼・法・契約のみに使用。

### 1.3 現状と保存状況

現在、完全な文章として残るは：

- **風の契約書 原本**（精霊協会 厳重保管） - 108通の精霊契約式
- **王国法典 写本**（Astralis法廷 所蔵） - 古語条文256条
- **外交文書 断片**（各国大使館 保管） - 条约50通中7通が原文
- **詩歌集「風の詩」**（月エルフ王国 図書館） - 断片34篇

復元プロジェクトは精霊協会主导で進行中（アールディー1070年完了予定）。しかし、**音声の消失**（発音記録なし）と**文法の不定形**（多種族混在のため）が課題。

## 2. 言語学的特徴

### 2.1 音韻体系（復元推測）

**音素数**: 28音（現代共通語25音 + 3古音）

**母音 (7)**:

```
a, e, i, o, u (基本5母音)
ā (長音・契約)    → アー
ē (長音・外交)    → エー
```

**子音 (21)**:

```
P, B, T, D, K, G
S, Z, Š (sh), Ž (zh)
M, N, Ŋ (ng)
L, R
F, V, H
C (ts), J (y), W, Y
```

**特徴的発音**:

- 全音節が**CV（子音+母音）構造**（発音容易）
- 長母音は**契約・外交の強調**に使用（例: `zēpha`「風よ」 vs `zepha`「風」）
- 声門摩擦音 `h` は精霊名にのみ出現（精霊語からの transfer）

### 2.2 文法構造（最簡素設計）

**基本語順**: SVO（主語・動詞・目的語）← 現代共通語と同一

**名詞**:

- **4格**: 主格・属格・対格・呼格（機能最小）
- **性**: 無性（全名詞中性）← 多種族考慮
- **数**: 単数・複数（双数なし）
- **人称**: 3人称のみ（1・2人称は後代追加）

**動詞**:

- **4時制**: 現在・過去・未来・完了（最小限）
- **2様式**: 指示・命令（願望・推論は後代追加）
- **人称・数一致**: なし（多種族のため複雑化回避）

**特徴的構文**:

1. **契約構文**: `X wa Y wo musubu`（XはYと契約する） - 固定句
2. **外交構文**: `X kara Y he`（XからYへ） - 移動・ transfer の基本
3. **精霊呼びかけ**: `O [精霊名]`（O+精霊名） - 呼格の特殊形

### 2.3 語彙特性

**核心語彙領域**:

1. **契約関係** (50語): 契約、約束、証、 etc.
2. **外交・政治** (80語): 交渉、条約、同盟、 etc.
3. **風・空** (40語): 風、空、旅、 etc.
4. **精霊関連** (60語): 精霊名、契約式、 etc.
5. **多種族共通** (100語): 種族名、共通概念

**語形成**:

- **複合語**: 少ない（単語は単独が基本）
- **接辞**: 接頭辞3種、接尾辞2種のみ
- **借用語**: 多種族語から積極的に借用（全語彙の30%が借用）

**数字**:

- **10進法**: 1-10の基本語 + 複合（11=10+1）
- 100=`hyaku`, 1000=`sen`（後の共通語に直接 transfer）

## 3. 文字体系：風紋文字（Zephyr Script）

### 3.1 基本設計思想

- **80文字** = 風の8方向（北・北東・東・南東・南・南西・西・北西）×10段階（弱→強）
- 文字形状は**流線形・曲線的**（風の軌跡を模倣）
- 書写速度を重視（**実用性最優先**、Lunariaの神秘性・Grandoriaの幾何学性と対極）

### 3.2 文字分類（8系統 各10文字）

#### 北系 (North, 風上) - 10文字

```
基本形: 上向き曲線 ──>  ──>  ──> etc.
段階: 1(微風) → 10(疾風)
```

#### 北東系 (NE) - 10文字

```
基本形: 右上がり曲線
```

#### 東系 (East) - 10文字

```
基本形: 右向き曲線
```

#### 南東系 (SE) - 10文字

```
基本形: 右下がり曲線
```

#### 南系 (South) - 10文字

```
基本形: 下向き曲線
```

#### 南西系 (SW) - 10文字

```
基本形: 左下がり曲線
```

#### 西系 (West) - 10文字

```
基本形: 左向き曲線
```

#### 北西系 (NW) - 10文字

```
基本形: 左上がり曲線
```

**例示**:

```
弱風 (1): ～ (軽い曲線)
            ／
中風 (5): ～～ (中程度の曲線)
            ／＼
強風 (10): ～～～ (激しい曲線)
            ＼／
```

### 3.3 書法规则

1. **方向自由**: 文字は風の向きに従って描く（上・下・左・右・斜め）
2. **速度重視**: 1文字平均0.5秒で書ける（実用性最大化）
3. **連続化**: 隣接文字を**連結可能**（風紋の連続性）
4. **インク**: 鉄インク（黒）・風精霊の羽インク（青）など

### 3.4 数字・日付表現

- **数字**: 10進法（1-10の基本文字をそのまま使用）
  - 1: 北系1（上向き微風）
  - 2: 北東系1（右上がり微風）
  - ...
  - 10: 北系10（最強上向き風）
  - 11: 10+1 で `強い上向き+微風` の組み合わせ
- **日付**: 年・月・日を風向きで表現（例: 春は東系、冬は北系）

## 4. 文化的・魔法的意義

### 4.1 魔法における地位

- **風魔法詠唱の基本言語**: 風魔法には必須（Zephyros精霊の名を呼ぶ）
- **契約魔法**: 精霊との契約はZephyr古代語でなければ無効
- **交渉魔法**: 説得・欺瞞魔法に bonus（言語の外交的性質）

### 4.2 外交・政治における地位

- **精霊協会公用語**: 全精霊との交信に使用（唯一の共通語）
- **国際条約本文**: 原本はZephyr古代語（条約解釈の基準）
- **十二国国会**: 公式議事録はZephyr古代語（現代語訳は参考）

### 4.3 社会階層と言語アクセス

- **精霊協会高位職**: 完全掌握必須（50名程度）
- **外交官・精霊術師**: 80%の語彙と基本術式（500名）
- **一般市民**: 10-20語（契約の言葉・日常挨拶）
- **他種族**: 外交官・商人のみ（学習容易なため広がりあり）

### 4.4 現代言語への影響度

- **共通語**: 語彙の40%・文法の70%がZephyr古代語由来（直系祖先）
- **エルフ語**: 外交用語10%が借用
- **ドワーフ語**: 技術外交用語5%が借用
- **オーク語**: 契約用語3%が借用

### 5.2 代表的な術式（5例）

#### 術式1: **風精霊との契約** (Zephyros-Musubu)

```
O Zephyros wa watashi wo musubu,
Kō yaku shō,
Kaze sora tabi.
```
