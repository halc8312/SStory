# Lunaria古代帝国語 - エターナル・アルカディア

**別名**: 月影古典語、第一精霊語、星詠みの言葉
**時代**: 古代期（-5000年 ～ -3000年）
**使用文明**: Lunaria帝国（月の魔法文明）
**現在の話者**: **47人**（2026年1月1日時点、精霊協会最高顧問10名＋月魔法 Grand Master 37名）
**文字数**: 108文字（月运行的周期に基づく）
**文書形式**: 石板・月光結晶・星盤

---

## 1. 歴史的概要

### 1.1 起源と成立
Lunaria古代帝国語は、**精霊語（月の精霊Lunaの直接通信）** を人類（当時は純血エルフのみ）が解析・体系化した最初の言語である。紀元前5000年、三精霊契約時代の初期に、Lunaの加護を受けた**月の巫女達**が夢で受けた啓示を文字化したことが起源とされる。

**成立の特徴**:
- 月の満ち欠け（108夜 cycle）に基づく108文字
- 各文字が特定の月相位・魔力波長・精霊階層に対応
- 時間・予言・幻覚魔法の詠唱に必須
- 文字そのものが**微細な魔導回路**として機能（石板に刻むと微弱な月魔法が発動）

### 1.2 繁栄と変遷
**-5000年 ～ -4000年**: 純粋な儀式言語として使用。Lunaria帝国の国語となる。
**-4000年 ～ -3000年**: 帝国衰退とともに simplification（簡略化）が進み、中世エルフ語の原型となる。
**-3000年**: 月塔崩壊事件により、Master Text「月光紀典」の9割が失われ、言語の大半が断絶。

### 1.3 現状と保存状況
現在、解読可能なのは以下のみ：
- **月光紀典 断章I～III**（Astralis魔法学院 所蔵）
- **月の預言書 十三巻**（月エルフ王国 宮殿内 神殿）
- **精霊契約式文 百八式**（精霊協会 厳重保管）

復元プロジェクトが精霊協会と月エルフ王国により進行中（2050年完成目標）。

## 2. 言語学的特徴

### 2.1 音韻体系（復元版）

**音素数**: 36音（現代エルフ語24音 + 12古音）

**母音 (8)**:
```
ī (長音・神秘)    → イー
ü (月の虹)        → ユ
ē (永遠)          → エー
ō (循環)          → オー
á (月影)          → ア・アクセント
ú (星霜)          → ウ・アクセント
ŵ (魔力共鳴)      → ウ・唇音化
ŷ (予言振動)      → イ・高音
```

**子音 (28)**:
```
P, B, T, D, K, G (無声音・有声音 対)
S, Z, Š (sh), Ž (zh) （風の音）
M, N, Ŋ (ng) （共鳴音）
L, Ł (暗いl), R, Ř (trill) （液体音）
F, V, X (harsh), H (breathy) （気流音）
C (ts), J (y), W, Y
```

**特徴的発音**:
- 母音の長短で意味が180°変化（例: `sīla`「月の扉」 vs `sila`「月の影」）
- 特定の子音連続（`kř`, `tř`）は精霊名を含むため禁忌語に指定
- 母音の「月 wave」 (`ī → ō → ŷ`) が呪文の三段階完了を表す

### 2.2 文法構造

**基本語順**: VSO（動詞・主語・目的語）← 精霊語の影響

**名詞**:
- **8格**: 主格、属格、与格、対格、具格、経格、向格、呼格
- **性**: 3性（陽・陰・中性）＋ **精霊性**（精霊名含む語に自動付与）
- **数**: 単数・双数・複数（双数は「対となる精霊・双子・月と太陽」のみ）

**動詞**:
- **12時制**: 現在・近過去・遠過去・過去完了・未来・近未来・遠未来・未来完了・永久・伝説・神話・予言
- **4様式**: 指示・命令・願望・予言
- **人称**: 1/2/3人称 × 単数/双数/複数 × 敬称/平称/蔑称（合計54活用）

**特徴的構文**:
1. **月詠み構文**: 目的語を文頭に置き、月光を暗示（詩的・呪文的）
   - 例: `Luna-ken sīra`（月-対格 扉-開け）→ 「月よ、扉を開けよ」
2. **時空倒置**: 過去の事実を未来形で述べる（予言文体）
   - 例: `Tertī ālēsa`（第三-帝国-崩壊する）→ 「第三帝国は（かつて）崩壊した」（予言書式）

### 2.3 語彙特性

**核心語彙領域**:
1. **月関係** (120語): 月相、月光角度、月齢、月の魔力、 etc.
2. **精霊名** (108語): 各精霊の真名（五大精霊＋108の下属精霊）
3. **時間** (85語): 未来・過去・予言・時間歪みに関する独自概念
4. **魔法術式** (200語超): 詠唱用語、呪文構造素

**語形成**:
- **複合語**が主流（例: `Lunatīs-ēna`「月詠みの歌」= Luna + tīs + ēna）
- **接辞**: 前置辞・後置辞双方あり（月の満ち欠けを符号化）
- **借語**: ほぼなし（孤立文明のため）

## 3. 文字体系：月光文字（Lumina Script）

### 3.1 基本設計思想
- **108文字** = 月の108夜 cycle（各文字が1夜に対応）
- 文字形状は**三日月・満月・新月・月食**の4形態を基本
- 文字は単独で**微弱な月魔法**を発動（石碑に刻むと夜間微弱発光）

### 3.2 文字一覧（一部例示）

#### 母音文字 (8):
```
ī: 〇（満月）       ō: ●（満月+中心点）
ü: ◐（三日月左）     á: ◑（三日月右）
ē: ○（環）         ú: ◉（環+点）
ŵ: ⚪（二重環）      ŷ: ⚫（二重環+点）
```

#### 子音文字 (28) - 月の形相別分類:

**無声音 (14)** - 新月型 `◱`:
```
P: ◱＋点   T: ◱＋線   K: ◱＋角   S: ◱＋芒
F: ◱＋芒二本  H: ◱＋波線  C: ◱＋鋸歯  Š: ◱＋斜線
```

**有声音 (14)** - 満月型 `◰`:
```
B: ◰＋点   D: ◰＋線   G: ◰＋角   Z: ◰＋芒
V: ◰＋芒二本  Ž: ◰＋斜線  Ř: ◰＋環   M: ◰＋中央点
```

**特殊文字 (12)** - 月食・ halo型:
```
Λ (Luna-神): ◑＋十字   Σ (星): ◐＋五点   Φ (予言): ○＋三叉   etc.
```

### 3.3 書法规则
1. **月光順**: 文字は左から右、上から下（通常）だが、**月詠み文書**では円形に配置（月光の波動を表現）
2. **文字の大きさ**: 月相に応じ変幻（満月文字=大、新月=小）
3. **インク**: 月光結晶粉末を混合した特殊インク（夜間のみ可読）
4. **読む条件**: 月の位置・角度により解読可能文字が変わる（暗号化のため）

### 3.4 数字・日期表現
- **数字**: 108進法（月の夜数に基づく）
  - 1-9: 基本記号
  - 10-99: 組み合わせ
  - 100-108: 特殊記号（108は「完全」の聖数）
- **日期**: 月相＋夜数（例: `Luna-Ⅲ-27` = 第3月周期27夜）

## 4. 文化的・魔法的意義

### 4.1 魔法における地位
- **月魔法詠唱の必須言語**: 月魔法は全てLunaria語で詠唱しないと効果0.1%以下
- **予言魔法**: この言語以外では不可能（予言の「時空 invariance」に依存）
- **精霊術**: Luna精霊と直接交信可能（現代エルフ語では不可能）

### 4.2 宗教的儀礼
- **月の祭典**: 108周期に合わせた儀式でLunaria語詠唱必須
- **精霊讃美歌**: 全108曲がLunaria語原文保持（現代語訳は無効）
- **死後儀礼**: 死者の名をLunaria語で唱えることで来世への扉が開く

### 4.3 社会階層と言語アクセス
- **最高魔導士階級**: 108語全ての真名を知る（10人限定）
- **月魔法師**: 50-80語の術式語のみ
- **一般エルフ**: 10-15語の儀礼語のみ（「月の加護を」など）
- **人間**:  virtually 0（学習不可能）

### 4.4 文化的影響
- **現代エルフ語の漢字**: 約30%がLunaria語からの loanword（神秘・魔法関連）
- **月名**: 10ヶ月の月名はLunaria語起源
- **占星術**: 星の名称はLunaria語の constellations に由来

## 7. 文化的・歴史的重要性

### 7.1 三文明との関連
Lunaria古代帝国語は三つの古代文明で唯一**完全に言語体系が残っている**（他の二文明は言語断片のみ）。これは月魔法の保存性の高さと、月エルフが言語を文化の核心と捉えるため。

### 7.2 現代言語への影響度
**エルフ語**: 語彙の40%がLunaria語起源（特に神秘・魔法・月関係）
**共通語**: 単語15語程度（主に月関係: `lunar`, `phase`, `prophecy` 等）
**精霊語**: 月精霊語はLunaria語の直系子孫（実際、同一言語とされる）

### 7.3 禁忌と伝承
- **108文字全てを一瞬に唱える**と、Luna精霊が顕現する（過去2例、1例は成功、1例は死亡）
- **13の予言書を完読**すると、未来が固定化される（时间为止まる）
- **月光紀典原本を太陽光で読む**と、読者は石化和む（実際の事件3件）
- **Křīsa（呼ぶ）** の文字は単独使用禁止（無自覚に精霊召喚）
